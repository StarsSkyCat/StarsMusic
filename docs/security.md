# 安全与数据约定

本文约束当前桌面、本地播放、网易云与酷狗接入，以及可选 SQLite 加密登录保存。默认仍是临时会话；只有用户启用“记住登录”且本地存储/密钥可用时才写入加密凭据。

当前窗口启用 sandbox、contextIsolation，关闭 Node 与 webview，使用内存 session，拒绝权限、下载、导航和新窗口。CSP 限制资源与连接来源。preload 只暴露 getAppInfo、appearance、playback、netease、kugou、presentation、credentials 的具体方法；主进程验证窗口、主帧、文档 URL 与各命令参数，响应/事件执行白名单投影。扫码在官方 App 授权，尚无官方授权网页窗口。

## 凭据与账号

登录由用户在官方流程中授权。禁止要求用户把真实 Cookie、密码或 Token 粘贴到聊天、Issue、PR、配置示例或测试记录。首版优先扫码及隔离官方窗口，不实现密码收集。

凭据只在后台处理。当前经用户选择改用应用管理的随机 32 字节密钥和 AES-256-GCM，凭据密文放入 SQLite，本地密钥单独保存，Linux 目录 0700、文件 0600；无需 GNOME Keyring/KWallet。数据库元数据只保存平台键、记住开关、更新时间和版本，账号 ID、昵称、Cookie、Token、设备标识均在密文内。同步数据库操作只在专用 Node worker 中执行，不开放 SQL、文件路径或凭据 IPC 给 renderer。

本地密钥没有系统密钥库的隔离：能同时读取密钥和数据库的程序/用户可解密凭据，UI 明确提示这一取舍；不能将其声称为保护同用户恶意程序或整目录备份泄漏。加密有随机 nonce 和认证标签，数据被篡改或密钥不匹配时拒绝解密；已有密文而密钥丢失时不自动创建新密钥替换。存储失败时保留临时会话并报告原因。

用户显式启用“记住登录”后才保存，退出平台或关闭记住会删除对应密文；明确“清除已保存登录”重建凭据库并删除本地密钥。安全删除不能保证物理介质、系统备份或外部副本中的数据被擦除。启动恢复仍由 Provider 重新核对账号，登录保存不延长平台 Token 的有效期。旧系统密钥文件只在新库尚未初始化且可正常解密时转换，完整事务提交后才删除旧文件；不可解密时保留，需用户重新扫码，不使用 basic_text 解密来源。细节见 [凭据说明](credentials.md)。

平台、账号、客户端渠道共同参与缓存和会话边界；退出使旧请求失效并清理私有缓存及授权窗口数据。

SessionGeneration 守卫只允许当前租约写回；网易云与酷狗服务都实际调用它取消旧请求，并清理内存凭据、二维码和私人列表。后台使用独立 utilityProcess，stdio 被丢弃；不写共享匿名 Token 文件、不加载环境凭据、不输出原始响应。主进程在进程重启后继续递增公开 generation，停止相关在线播放；不把不同账号/进程的同号结果当作有效新会话。utilityProcess 是生命周期与内存隔离边界，不是无权限安全沙箱。

酷狗 App 扫码在后台生成随机的进程内 GUID/MID，注册载荷只包含应用自报的品牌、设备名和随机标识，不读取或采集硬件、传感器、IMEI 或系统设备信息。`dfid`、Token、`userid`、二维码 key 与歌单/曲目参数不进入页面；页面只拿公开 ID。SSA 安全验证只归类为 `verification-required` 提示用户在官方 App 处理，不自动生成绕过验证码的行为指纹。仅在 `STARSMUSIC_DEBUG=1` 时输出酷狗媒体主机、取链字段名、hash 前缀、时长和权限字段；不输出完整签名 URL、Token、账号标识或歌曲名。

## IPC、网络与媒体

renderer 不能直接获得 Node、任意 IPC、文件系统、子进程或凭据 API。preload 只暴露具体操作，主进程验证调用来源、参数与权限。

授权窗口独立 session，无 Node 集成和业务 preload；跳转域名限制在经验证的授权链。URL、请求头和外部响应视为不可信输入，保留 TLS 校验。

mpv 使用私有 IPC、明确的进程所有权与参数数组；请求头不能写入命令行，跨平台切换时清理，重定向不得泄露平台凭据。完整签名媒体 URL 不写入持久日志。

页面只发送本地登记 ID 或当前账号已读取的网易云/酷狗曲目 ID，不能传任意路径、URL、API 参数或 mpv 命令。平台歌单 ID、酷狗 hash/album 参数只在后台登记映射中使用。mpv 用 shell=false 启动，Linux 使用继承 FD 3，Windows 使用每实例随机且由 mpv 限制当前用户及完整性级别的命名管道，命令 IPC 不开放 TCP 端口。Linux 关闭 FD、Windows 发送 quit，必要时终止进程。禁用配置、脚本、视频、旁加载与间接文件引用，每首先退出旧实例再清空头、加载新资源；不支持无缝切换。

在线媒体经随机令牌保护的 loopback HTTP 网关读取，逐跳校验且最多三次跳转。网易云只允许 HTTPS `.music.126.net`，酷狗只允许已核实/公开实测的 `fs-open`、`fsandroid`、`fsmobile` 媒体主机；网关按平台隔离，拒绝跨平台跳转。DNS 拒绝环回/普通私网/链路本地，兼容 198.18.0.0/15 Fake-IP 代理；TLS 按原始官方 CDN 名称验证且从未关闭证书校验。只转发音频 Accept/单 Range，不转发 Cookie、Authorization，也不回传上游 Set-Cookie。页面不接触媒体 URL。产品无静音降级开关，null 输出仅由测试显式构造。

StreamResolution 仍为后台专用，包含敏感临时地址，不能加入页面 IPC；通用结构校验不替代每个平台的传输策略。网易云与酷狗仅接受无 Cookie 头的资源，并在开始播放时检查声明的有效期；酷狗非完整权限必须由平台给出试听边界。实际链接过期恢复仍需独立验证。错误只返回本地固定分类、文案和重试标记，不透传平台返回、异常 message、stack 或 cause。

## 数据与记录

本地数据库、日志、截图和扫描结果可能包含个人信息，不能提交仓库。测试响应只保留必要字段并脱敏，验证记录不保存完整原始平台返回。

忽略规则是减少误提交的辅助措施，不能替代提交前检查。新增环境变量时提供无秘密的示例，真实值只在本机管理。

源码推送前同时检查待推送的提交历史与当前文件树，不能只检查最后一个版本；历史里曾提交后又删除的数据仍会被推送。账号导出 JSON、Cookie/Token 导出、HAR 网络记录和本地 Electron profile 目录也已加入忽略规则。测试所需的合成账号/凭据保留明确的 synthetic/合成标记，不使用真实测试登录响应。截图、日志和运行时数据继续留在忽略目录，不纳入源码提交。首次 main 合并前的检查范围与结果见 [推送前数据检查](validation/2026-10-27-main-merge-audit.md)。

发现泄漏时停止继续传播，记录不含秘密的问题描述；由用户通过平台官方入口撤销会话或相关密钥。不在未经授权时修改平台账号或公开发布问题细节。
