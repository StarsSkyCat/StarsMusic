# 安全与数据约定

本文约束后续实现；当前尚无账号、凭据存储或在线请求代码。

## 凭据与账号

登录由用户在官方流程中授权。禁止要求用户把真实 Cookie、密码或 Token 粘贴到聊天、Issue、PR、配置示例或测试记录。首版优先扫码及隔离官方窗口，不实现密码收集。

凭据只在后台处理，系统安全密钥后端不可用时采用临时会话。不能把“加密 API 返回可用”当作保护有效的证明。官方窗口的会话存储与业务凭据都要检查，避免退出后残留副本。

平台、账号、客户端渠道共同参与缓存和会话边界；退出使旧请求失效并清理私有缓存及授权窗口数据。

## IPC、网络与媒体

renderer 不能直接获得 Node、任意 IPC、文件系统、子进程或凭据 API。preload 只暴露具体操作，主进程验证调用来源、参数与权限。

授权窗口独立 session，无 Node 集成和业务 preload；跳转域名限制在经验证的授权链。URL、请求头和外部响应视为不可信输入，保留 TLS 校验。

mpv 使用私有 IPC、明确的进程所有权与参数数组；请求头不能写入命令行，跨平台切换时清理，重定向不得泄露平台凭据。完整签名媒体 URL 不写入持久日志。

## 数据与记录

本地数据库、日志、截图和扫描结果可能包含个人信息，不能提交仓库。测试响应只保留必要字段并脱敏，验证记录不保存完整原始平台返回。

忽略规则是减少误提交的辅助措施，不能替代提交前检查。新增环境变量时提供无秘密的示例，真实值只在本机管理。

发现泄漏时停止继续传播，记录不含秘密的问题描述；由用户通过平台官方入口撤销会话或相关密钥。不在未经授权时修改平台账号或公开发布问题细节。

## 依赖与参考代码

引入依赖时检查实际用途、安装脚本、来源、许可和固定版本。参考项目的代码、品牌与视觉资产分别核实授权。正式发布前建立依赖清单及 mpv/FFmpeg 构建和许可记录。
