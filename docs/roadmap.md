# 路线图

更新：2026-10-28。当前能力见 [README](../README.md)，实际验收范围见 [测试说明](testing.md)。这里仅保留后续工作，版本号不代表稳定发行或所有平台均已验收。

## 发布前

- 完成网易云 / 酷狗真实账号跨重启恢复验收，以及会员、音质、试听、过期、限流和网络故障矩阵。
- 复测网易云喜欢、收藏、自建歌单增删的真实写入与回读；复测酷狗官方授权取链成功、曲目身份和实际出声。
- 补齐 Windows 内置 mpv / FFmpeg 及静态链接库的完整许可、对应源码与构建材料，完成 Electron / Chromium 和生产依赖的发行清单。
- 验证 Windows 跨版本升级、卸载数据行为、签名及公开分发；覆盖更多 Windows 版本、缩放、音频设备与格式。
- 扩大 Linux 发行版、GNOME / KDE、X11 / Wayland、音频与桌面能力实机矩阵，验证实际安装包。

## 音乐与体验

- 本地目录导入、标签索引、内嵌封面与旁置歌词、SQLite 音乐库迁移。
- 独立最近播放和跨队列历史、完整实际音质展示。
- 酷狗收藏与歌单编辑；更多云端能力按真实接口和授权结果逐项推进。
- 评估无缝播放、均衡器、逐字歌词、歌词翻译和桌面歌词。

## 平台与分发

- Windows 通知、系统媒体面板、专用媒体键和任务栏媒体控件。
- Linux AppImage、DEB、RPM；后续评估 Flatpak 和 ARM64。
- macOS 系统能力、音频、打包和实机验证。

计划项需按实际需求和验证结果推进；未列出的 SDK、数据库绑定或发行工具不提前安装。
