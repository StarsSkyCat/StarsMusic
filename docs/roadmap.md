## P0：接入和分发可行性

按顺序实现，每项验证记录使用 [模板](templates/p0-validation.md)。

1. **桌面基础（已实现）**：安全 BrowserWindow、受限 preload、应用信息 IPC 和最小页面；已加入 dev/build/typecheck、边界测试与桌面 E2E。验证范围见 [记录](validation/2026-10-26-desktop-foundation.md)。
2. **公共契约（已实现）**：TrackRef、ProviderContext、登录/会话状态、StreamResolution、错误分类及运行时校验；后台会话 generation 支持取消与旧结果丢弃。使用约定见 [公共契约](contracts.md)，验证见 [记录](validation/2026-10-26-contracts-session.md)。尚未接入真实平台服务。
3. **音频闭环（本地已实现）**：mpv 私有继承 FD、临时本地队列、播放/暂停/定位/音量、快速切歌和退出清理；实际 mpv 集成与 PipeWire 桌面测试通过。范围见 [记录](validation/2026-10-26-local-playback.md)；线上资源与发行环境音频验证仍待后续接入。
4. **网易云接入（本次真实闭环通过）**：固定 api-enhanced 4.41.1 协议基线，独立后台进程实现临时 App 扫码 → 账号 → 歌单 → 解析 → 实际出声；已修复 Fake-IP DNS 代理兼容问题。见 [记录](validation/2026-10-26-netease.md)；完整权限/音质矩阵及链接过期恢复仍待补测。
5. **酷狗验证（App 扫码已实现，真实闭环待验证）**：选择标准版 App 扫码作为首个渠道，已实现设备注册、扫码/账号验证、私人歌单/曲目分页、流解析和单曲播放；匿名端点、合成响应、合成媒体与桌面启动通过。真实账号扫码、真实歌单和实际出声尚未由用户完成。网页登录未实现，保留为独立验证项。见 [酷狗说明](kugou.md) 与 [验证记录](validation/2026-10-26-kugou.md)。
6. **凭据验证**：系统密钥服务、临时会话模式、重启恢复、锁定、退出与旧请求取消。
7. **Linux 验证包**：AppImage 与原生包；代表 GNOME/KDE 环境，验证声音与最小 MPRIS 控制。

P0 完成标准：两个平台各有一条可重复的登录—歌单—实际播放路径，并有至少一个可运行 Linux 验证包。没有真实账号或环境验证时保持待办，不用 Mock 标记完成。
