## P0：接入和分发可行性

按顺序实现，每项验证记录使用 [模板](templates/p0-validation.md)。

1. **桌面基础（已实现）**：安全 BrowserWindow、受限 preload、应用信息 IPC 和最小页面；已加入 dev/build/typecheck、边界测试与桌面 E2E。验证范围见 [记录](validation/2026-10-26-desktop-foundation.md)。
2. **公共契约（已实现）**：TrackRef、ProviderContext、登录/会话状态、StreamResolution、错误分类及运行时校验；后台会话 generation 支持取消与旧结果丢弃。使用约定见 [公共契约](contracts.md)，验证见 [记录](validation/2026-10-26-contracts-session.md)。尚未接入真实平台服务。
3. **音频闭环（本地已实现）**：mpv 私有继承 FD、临时本地队列、播放/暂停/定位/音量、快速切歌和退出清理；实际 mpv 集成与 PipeWire 桌面测试通过。范围见 [记录](validation/2026-10-26-local-playback.md)；线上资源与发行环境音频验证仍待后续接入。
4. **网易云接入（本次真实闭环通过）**：固定 api-enhanced 4.41.1 协议基线，独立后台进程实现临时 App 扫码 → 账号 → 歌单 → 解析 → 实际出声；已修复 Fake-IP DNS 代理兼容问题。见 [记录](validation/2026-10-26-netease.md)；完整权限/音质矩阵及链接过期恢复仍待补测。
5. **酷狗验证（受限通过）**：选择标准版 App 扫码作为首个渠道，已实现设备注册、扫码/账号验证、私人歌单/曲目分页、流解析和单曲播放。用户已确认登录、私人歌单、曲目列表和部分歌曲实际出声；此前“名称与声音不一致”的根因是取链附带可能错配的云歌单 album/audio ID，已改为只按主 hash 取链并保留身份校验。后续修复请求 50/翻页 300 的漏歌问题、取消时长/模糊名称身份兜底和整曲时长充当试听上限；随后补充[官方资源编码关系核验](validation/2026-10-26-kugou-encoding.md)，修正同曲不同编码被误拒；[两首歌的可用性差异](validation/2026-10-26-kugou-resource-access.md)尚未在用户登录态闭环确认。部分曲目仍因 `status=3`/`35104` 等平台限制不可用，完整权限/音质矩阵待验证。网页登录未实现，保留为独立验证项。见 [酷狗说明](kugou.md) 与 [验证记录](validation/2026-10-26-kugou.md)。
6. **凭据验证（SQLite 已实现）**：按用户选择改为本地随机密钥 + AES-256-GCM + SQLite，不依赖系统密钥服务。实际 SQLite/AES 自动化验证双平台加密、重建恢复、损坏/丢失密钥、事务回滚、旧文件转换与迟到操作；桌面 E2E 验证 basic 密码库环境下的启用、清除和实际应用重启。真实账号重启后平台验证仍待用户完成。见 [凭据持久化](credentials.md) 与 [SQLite 记录](validation/2026-10-26-sqlite-credentials.md)。
7. **Linux 验证包（本机 Arch 已安装验证）**：Arch x86_64 原生包、Wayland/X11、PipeWire 与 MPRIS 的实际包检查见 [记录](validation/2026-10-27-arch-package.md)。已用 pacman 安装并复测实际安装路径，状态以该记录为准；AppImage/DEB/RPM、GNOME/KDE 与其他发行版矩阵仍待验证。

P0 完成标准：两个平台各有一条可重复的登录—歌单—实际播放路径，并有至少一个可运行 Linux 验证包。没有真实账号或环境验证时保持待办，不用 Mock 标记完成。
