# 平台接入

网易云与酷狗独立登录、独立会话，公开元数据可匿名浏览；私人歌单和播放按当前账号实际权限处理。账号已连接、套餐有效、歌曲标记 VIP 和资源实际可播放是不同状态，不能互相推断。

## 当前能力

| 能力 | 网易云 | 酷狗 |
| --- | --- | --- |
| 登录 | 官方 App 扫码与账号校验 | 标准版官方 App 扫码、设备注册与账号校验 |
| 浏览 | 分类公开歌单、详情、歌曲 / 歌单搜索、私人歌单分页 | 发现歌单、详情、歌曲 / 歌单搜索、私人歌单分页 |
| 播放 | 单曲、整单、多选下一首、完整 / 试听状态 | 单曲、整单、多选下一首；部分曲目权限 / 资源仍受限 |
| 内容写入 | 喜欢、自建歌单单曲增删、公开歌单收藏已有实现，真实写入待验收 | 歌单只读，收藏和编辑尚未实现 |
| 展示 | 行级歌词、封面、套餐同步与歌曲权限标记 | 行级歌词、封面、套餐同步与歌曲权限标记 |

用户曾确认网易云扫码、歌单和实际出声；酷狗扫码、私人歌单和部分曲目出声也有用户反馈。完整会员 / 音质矩阵、真实账号跨重启恢复和酷狗新增授权链的成功播放尚未完成验收，不能将匿名探测或合成测试视为通过。

## 登录与隔离

二维码只在内存显示，由用户用对应官方 App 扫码确认；收到扫码成功仍需后台账号接口核验身份。未实现密码登录、凭据粘贴导入或官方网页授权窗口，不读取浏览器登录态。

凭据只在可信后台使用。默认临时会话；用户在对应平台二维码区域选择记住登录后才加密保存，重启仍需请求平台重新验证账号。取消、退出、切账号、扫码重试和后台崩溃使旧请求与状态失效，两个平台互不覆盖。

酷狗采用 kugou-app 渠道，网页 Cookie 与 App Token 不混用。注册用随机进程内 GUID / MID，不采集硬件标识。SSA 等额外验证提示用户到官方 App 处理，不伪造验证行为。退出清除的是本应用的本地会话，不保证撤销平台其他设备的会话。

## 资源与权限

平台曲目由后台登记，页面只能传具体领域请求和登记 ID，不能提交任意接口或媒体地址。音乐库统一搜索复用两个平台的公开浏览接口，并匹配已加载本地文件和已同步私人歌单名称；没有扫描全部本地文件或索引私人歌单内所有曲目。

网易云只实现当前需要的固定端点，实际音质与试听以资源响应为准。酷狗以原主 hash 取链，避免云歌单 album / audio ID 错配；同曲其他编码必须经原 hash 对应的官方资源关系与曲名 / 版本核验，不能靠时长或模糊名称兜底。

酷狗旧取链不可用时，可尝试同一标准版账号的官方账号验证 → 单曲授权 → 授权取链。授权 proof 仅存在于本次后台调用，仍检查会话和切歌代次。此分支已有合成回归；真实账号成功、准确私人歌单 hash 与出声仍待复测。无资源或没有明确试听边界时如实报告，不把非空地址或整曲时长当作完整权限。

媒体地址、Cookie 和签名不进入 renderer、数据库或日志。在线音频经平台隔离的本机网关读取；封面限后台登记资源与校验后的内存图片。安全边界见 [安全说明](security.md)。

## 会员显示

两平台标题右侧的昵称入口展示连接状态和小号会员标记，点击后提供登录/退出及同步权益。会员状态只影响展示，不改变单曲实际取链权限。

酷狗同时读取账号资料和联合会员接口顶层 `vip_type` / 有效期，以及独立 `busi_vip` 套餐；顶层普通 VIP 不再要求附带套餐数组。`vip_type=6` 单独归一化为超级 VIP，显示 SVIP；独立产品代码 `svip` 是概念版 VIP，显示 VIP，不混为超级会员。来源为现有[固定协议基线文档](https://github.com/MakcRe/KuGouMusicApi/blob/62730f900dc9fdc51396a663b3d33a6c4c704046/docs/README.md)，顶层与套餐字段的兼容参考 [UserVip 字段说明](https://docs.rs/kugou_sdk/0.2.9/kugou_sdk/user/struct.UserVip.html)。

按账号与来源暂存在内存中的已确认权益在刷新或暂时失败时保留，过期/未开始权益不展示；成功非会员响应撤销该来源的旧结果。退出/切账号清空，迟到响应不写回。部分同步失败在账号面板中提示；未知会员不会显示 VIP。当前有合成响应与界面验证，用户普通 VIP 的真实账号复测仍待完成。
