# 酷狗歌单、曲目身份与试听权限排查

日期：2026-10-26；本开发机 Linux x86_64 / Node 24.22.1 / Electron 45 / mpv 0.41 / PipeWire。状态：代码中已确认的问题已修复；用户两首歌的登录态差异仍待复测，不能宣称全部会员曲目或官方权限矩阵已通过。

## 用户反馈和证据边界

用户反馈 A《给你呀》—将小呢在官方显示没有资源，B《错位时空》—艾辰在官方正常，而本应用相反；本人没有开酷狗会员，但还发现歌曲不限时播放。仅涉及酷狗，未发现网易云同样问题。歌曲名称由用户主动提供，不含账号、私人歌单、二维码或凭据。

本轮没有读取用户凭据或自动登录。通过标准版匿名公开搜索筛选歌曲后，仅检查对应 hash 的 128kbps 完整/试听取链响应及匿名资源信息，不下载音频，不写入媒体地址或原始响应：

- 《给你呀》搜索结果的歌手为“将小呢、for ya”；对应标准资源完整/试听两次均为 `status=3`、无 URL。
- 《错位时空》搜索结果的歌手为“艾辰”；对应标准资源完整/试听两次也均为 `status=3`、无 URL。
- 两条匿名资源信息均回显请求 hash，标准 MP3 条目 `status=0`、`privilege=5`。没有把 5 猜测成会员不足或下架；匿名结果不能代替用户登录后的官方行为，也不能证明私人歌单登记的是同一 hash/版本。
- 同名其他歌手的资源可以出现完整请求无地址、试听请求返回 URL 及整曲 `timeLength` 而没有试听边界。这验证了 `timeLength` 不适合当作试听授权上限；没有据此播放或保存该地址。

上述是单次在线观察，平台响应可能变化，不作为自动化快照。临时排查脚本执行结束后移除，没有新增产品搜索/权益端点。

## 确认并修复的问题

1. **分页不一致**：service 与 IPC 使用每页 300 条，transport 却发送 `pagesize=50`。请求与翻页现在共用 `kugouTrackPageSize=300`，测试实际请求体及 301 首的两页边界，第二页取链核对登记 hash，不靠行号取歌。
2. **身份判断过宽**：过去允许“时长相差不超过 10 秒”“文件名相似词命中一半”确认另一 hash，甚至允许无返回 hash。现在完整播放要求 hash/std_hash 对应，文件名冲突立即拒绝；时长只做诊断。试听另 hash 也必须完整曲名与歌手前缀对应。冲突不再降级到宽松试听。
3. **试听时长误用**：旧分支用 `timeLength` 或默认 30 秒生成试听长度，可能把 254 秒整曲当 254 秒试听。现在只用平台明确起止边界，缺少边界显示“平台未确认完整播放权限或有效试听范围”，不制造权限。
4. **完整/试听分支**：明确完整授权保留；明确非完整、正试听范围或受限标志必须按试听处理。试听接口返回 URL 本身不代表完整授权；缺失权限字段也不默认为免费。无地址归为资源不可用，不宣称用户非会员无权。
5. 切换曲目清除上一首资源错误，并以解析序号丢弃旧取链晚到的错误，防止 A 的失败继续显示在正常 B 上。
6. 播放状态分别标记“完整播放”和“试听”，不将这些标签等同于账号会员等级。既有会话隔离、hash-only 取链、私有媒体网关与旧请求丢弃保持有效。

## 验证

- 文档检查与严格类型检查。
- 50 项单元测试：新增实际分页边界、A/B 曲目身份、同歌手不同歌、同名不同歌手、相同时长、缺失 hash、不同编码 std_hash、普通/明确完整/明确试听/权限未知响应。
- 5 项实际 mpv 集成测试（合成 WAV，显式 null 输出）：酷狗解析器接收到 10 秒资源但只有 1 秒试听授权，实际播放和可定位长度均不超过 1 秒；不采用整曲时长作为权限。
- 桌面 E2E 与构建：实际 Electron、后台进程和 mpv，默认系统输出 PipeWire；本地选择结果使用合成音频，保持原有 IPC/沙箱/退出清理检查，不自动扫码或截图私人数据。

测试运行完成后关闭测试进程以及此前本任务保留的 start / Vite preview 会话，不保留开发服务器、音乐播放进程或新的终端会话。
