# 酷狗文件名格式误拒排查

日期：2026-10-28；环境：Arch Linux x86_64、Node 24、Electron 45、mpv 0.41。已修复可复现的身份误判，用户本人“我喜欢”中的准确版本及登录态仍需复测。

## 反馈与匿名观察

用户提供“我喜欢”中的《虞美人》—熙宝、《给你呀（又名：for ya）》—蒋小呢，以及提示资源不可用的《错位时空》—艾辰。仅对公开歌曲进行匿名搜索与取链响应检查；没有读取用户凭据、私人歌单或下载真实音频，也没有保存二维码、签名 URL 或原始响应。

- 《虞美人》公开搜索返回歌手“熙宝”，试听取链的 hash 对应原曲，文件名却为“虞美人 - 熙宝”。旧校验仅兼容歌手前置，因此误判。修复后身份检查通过；本次匿名试听仍缺少明确完整授权或试听边界，最终为 `playback-access-unknown`，未实际播放。
- 《九万字 (Remix)(DJ笙版)》等公开版本的取链 fileName 只有基础曲名，hash 及资源详情完整名称均对应原版本。旧逻辑在资源核验后仍拒绝。修复后身份检查通过，后续试听请求明确 `is_full_audio=1` 时可解析为完整资源；这不是用户登录态或实际出声验证。
- 公开搜索中《给你呀》对应将小呢/蒋小呢的结果以及《错位时空》—艾辰，本次完整和试听请求均未返回地址（status=3）。不能据此判断会员、下架或本人登录后的资源可用性；明确“又名：…”格式用合成数据回归，尚未复现该私人条目的实际取链文件名。

## 修改边界

1. 完整名称比较兼容已知歌手后置；仅移除明确的“又名/别名/原名：…”标注，不把普通版本后缀全局忽略。
2. 文件名省略括号后缀时仍先拒绝，随后最多一次资源查询。只有原 hash 唯一匹配、资源完整名称与所选版本一致、实际返回 hash 明确属于该资源、文件名等于完整基础曲名时才接受。不同版本、不同基础曲名、只有 std_hash 关联或实际 hash 缺失仍拒绝。
3. 完整/试听授权独立判断。身份格式修复不补造试听范围，不取消平台限制，不换歌曲或音源；原会话 generation、解析序号和媒体主机白名单保持。
