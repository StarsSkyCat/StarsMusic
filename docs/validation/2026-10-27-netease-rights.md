# 网易云筛选菜单与会员权限

日期：2026-10-27。按用户要求去重分类、改进玻璃排序菜单，并展示官方会员与曲目权限。分交互与权限两步提交。

## 第一步：筛选交互

- 去掉右侧重复分类下拉，全部 12 个既有分类统一放在左侧按钮区域，小窗口允许换行。
- 热门/最新使用顶层 popover 玻璃菜单，双主题共用材质与文字语义色。鼠标点击触发器不出现额外描边；键盘焦点仍保留可见提示。
- 排序项采用 menuitemradio：当前项勾选，支持方向键、Home/End、Enter、Escape、Tab 与外部点击关闭；关闭后按需返回触发器。
- 已通过类型检查、构建、网易云桌面交互回归、文档与空白检查。

## 第二步：官方会员与单曲权限

- 新增无参数 refreshMembership，只查询当前账号的固定 VIP 端点。扫码或恢复账号验证成功后自动同步，每 5 分钟刷新，发现页与设置页提供手动入口。有效套餐按账号 ID、套餐类型和到期日校验，不把等级、昵称或失败响应当 VIP；信息缺失不误标无会员。会员数据不写页面存储。
- 会员同步会刷新当前公开/私人列表的单曲详情及权限，单次最多 1000 首，避免超出固定详情端点上限；其余曲目在实际播放时继续重新验证。退出清理计时器，旧账号会员响应、旧搜索或旧歌单详情都不能覆盖当前内容。已确认会员信息与单曲详情刷新失败分开处理，失败时明确提示。
- 对热歌、公开歌单、歌曲搜索及私人列表显示 VIP / 付费专辑 / VIP 音质三类官方标记。fee=0 可能免费或无版权，不据此承诺可播。独立 privileges 逐 ID 关联，st<0 标记不可用；pl 不被当作完整播放证明。未知类型保留未知。
- 原有取链接口继续使用当前账号登录态，请求码率由固定 128000 调整为基线默认 999000，让平台返回当前授权范围内的实际资源与码率；仅在返回音频之后投影完整或试听，保留试听时长限制。失败不尝试其他账号、音源或破解方式。当前并未实现官方所有音质档位、空间音频、数字专辑购买与下载功能。
- 单曲完整播放、试听和不可用独立于会员标签。会员拥有者也可能遇到付费专辑、地区版权或不可用曲目；未登录匿名列表只展示收费/版权元数据，不能替代账号播放验证。

固定来源为 api-enhanced 4.41.1 的 [vip_info.js](https://github.com/NeteaseCloudMusicApiEnhanced/api-enhanced/blob/2db6684453297ee86dec0492842f2320b08182d9/module/vip_info.js)、[song_url.js](https://github.com/NeteaseCloudMusicApiEnhanced/api-enhanced/blob/2db6684453297ee86dec0492842f2320b08182d9/module/song_url.js)、[song_detail.js](https://github.com/NeteaseCloudMusicApiEnhanced/api-enhanced/blob/2db6684453297ee86dec0492842f2320b08182d9/module/song_detail.js) 与 [收费/权限字段文档](https://github.com/NeteaseCloudMusicApiEnhanced/api-enhanced/blob/2db6684453297ee86dec0492842f2320b08182d9/public/docs/home.md)。没有引入整个 SDK、新依赖、任意请求接口或第三方音源。

## 验证与限制

- 类型检查、88 项单元测试和包含构建的 6 项桌面回归通过。新增服务回归覆盖收费类型、逐 ID 权限配对、过期/未知会员、账号身份校验、登录/恢复同步、旧账号响应、同步当前页、迟到页面、授权完整/试听和权限拒绝。
- 桌面用例明确注入合成会员与单曲权限投影，验证三类标签、实际权限状态投影、同步按钮及私人歌单中的不可用提示；不登录平台、不模拟音频出声。菜单回归覆盖点击、键盘、关闭与实际分类/排序请求。
- 显式匿名联网 probe:netease-discovery 通过：热歌与歌曲搜索真实返回 fee 标记，样本包含 VIP 与 VIP 音质，公开歌单详情与图片继续通过。只输出计数，不输出任何凭据、原始响应或媒体 URL。
- 隔离临时配置进行真实匿名桌面核验：VIP 标记、分类去重、玻璃菜单、鼠标触发无多余边框、双主题和 960×640 无横向溢出。截图仅含公开内容，位于忽略目录 artifacts/netease-rights-live-*.png。

真实 VIP / SVIP / 音乐包 / 过期账号、付费专辑已购与未购、地区版权及会员高码率音频的实机矩阵仍待人工验收。本次没有访问用户登录配置或要求粘贴凭据，不把合成回归或匿名 fee 标记称为真实会员权益验收。
