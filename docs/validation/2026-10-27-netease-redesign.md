# 网易云发现页重设计与真实封面

日期：2026-10-27。按用户要求重设计热歌、歌单、搜索与我的歌单，分封面能力与界面两步实现。

## 第一步：真实封面链路

- 新增具体 getArtwork IPC，只接受已登记资源的种类、ID、generation，不接受 URL。封面源来自当前歌单/搜索原响应，后台保留地址、页面仅接收栅格 data URI；无需新增平台端点、SDK 或依赖。
- 沿用现有 CDN、公共地址 DNS、大小、格式、超时和不携带凭据的图片下载规则。4 路上限、相同请求合并和 32 张内存缓存；退出/切账号清空和取消，旧图片不回写。
- 单元回归覆盖匿名公开歌单和搜索曲目、私人歌单封面、无图、非白名单、未登记资源、缓存、并发上限与退出迟到图片。UI 回归继续使用明确标识的合成状态，不包含真实私人封面。
- 已通过 typecheck、83 项单元测试、6 项桌面 E2E（含构建）、文档检查；显式匿名联网探测通过，公开歌单图片真实下载及栅格格式校验通过。不读取真实私人账号或二维码。

## 第二步：音乐空间界面

- 热歌改为 1 张主封面 + 2 张次封面的前三名舞台，配合排名、曲名、歌手与明确播放入口；下方保留完整分页列表、多选与下一首。舞台仅展示当前榜单真实前三名，不生成虚假热度、趋势或推荐理由。
- 发现歌单、搜索歌单、我的歌单使用真实封面网格，配合叠片材质、曲目数量与整卡点击。分类快捷按钮与完整下拉并存，热门/最新排序不变。公开详情、私人详情及音乐库内网易云歌单卡片也使用同一封面组件。
- 搜索改为大输入区、歌曲/歌单切换、Enter 提交、关键词建议和独立空状态；建议只作为搜索词示例，不冒充平台实时热搜。结果曲目带专辑封面，原播放/队列行为继续使用后台服务。
- 云瓷白使用深珊瑚红点睛，曜石黑使用柔珊瑚色；保留全局透明材质、侧栏和播放舱。按窗口宽度调整网格列数，矮窗口缩减头部，让内容靠前。焦点可见、原生表单、44px 操作区、减少动态效果均适配。
- 图片以 IntersectionObserver 可见性加载，共用 4 路队列与 32 张内存缓存；同一榜首在舞台和列表不重复请求。无图、损坏图片与请求失败显示默认图，不伪造歌单封面、不影响播放。
- 桌面回归补充：真实 preload getArtwork 的合成处理器验证图片成功、缺图、请求失败与可见性加载；原分类/搜索/分页/公开与私人详情/播放命令验证仍保留。该用例使用合成投影，不调用平台，不模拟音频成功。
- 使用隔离临时配置进行真实匿名桌面联网：热歌前三、公开歌单、公开详情、歌曲搜索和歌单搜索均实际显示平台图片；浅色、暗色及 960×640 最小窗口检查，截图仅含公开内容并位于忽略目录 artifacts/netease-redesign-*.png。未访问用户真实账号配置、二维码、私人歌单或音频地址。

最终 typecheck、文档检查、diff 空白检查和含构建的 6 项桌面 E2E 全部通过；后台第一步的 83 项单元测试通过。截图完成双主题与最小窗口目视检查，无横向溢出。

真实账号私人封面链路有合成服务回归，尚未由真实账号人工验收；本次没有新增登录方式、播放权限或发行平台能力。

## 私人歌单曲目封面补漏

- 问题：发现页的曲目表已提供封面插槽，但“我的歌单”进入私人详情后使用 App.vue 的另一张曲目表，该表没有接入封面，因此只显示默认音乐图标。后台已登记私人曲目的专辑封面，不需要新增接口。
- 修复：私人网易云歌单曲目表复用 NeteaseArtwork，按曲目 ID 和当前会话 generation 请求；保留可见性加载、并发限制和失败默认图。
- 验证：扩展隔离 Electron 的合成私人歌单用例，检查封面成功、缺图及请求失败；滚动到曲目后验证图片加载，确认请求包含正确的曲目种类、ID 和代次。截图仅含合成数据，位于 artifacts/netease-synthetic-owned-tracks.png。
- 已通过 pnpm typecheck、pnpm build、发现与私人歌单桌面回归、收藏操作桌面回归、底栏桌面回归、pnpm check 和 git diff --check。真实账号私人封面仍需用户重新打开歌单验收。
