# 音乐工作区界面与队列验证

日期：2026-10-26。环境：本开发机 Linux x86_64、Electron 45、mpv 0.41、PipeWire；不代表 Windows/macOS、发行包或发行版矩阵验证。

## 已实现

- 独立的音乐库、本地音乐、网易云、酷狗、账号与设置导航；石墨黑 / 雾紫基调、统一 Lucide 图标、星夜品牌横幅。
- 两个平台分别订阅真实会话状态，连接后读取歌单，支持只读歌单卡片、分页曲目、来源标识与已知时长。未接入在线搜索；顶部仅筛选已加载的歌曲、歌手或歌单。
- 单曲播放、复选框多选、按列表顺序加入下一首；后台统一队列支持插队、移除非当前项、清空后续曲目、EOF 顺序续播，最多 200 首。解析函数保留在可信后台，播放时才取链；退出仅移除对应平台项，当前项来自该平台时才停止。
- 常驻播放栏、右侧队列对话框、展开播放页；两处控制共用 PlaybackSnapshot。保留音量、实际进度、上/下一首、播放/暂停、停止、实际音质及试听说明。对话框使用原生焦点限制、Esc 关闭和焦点恢复；列表支持双击播放、键盘选择。
- 多选批量插队检查页面/会话 generation，切换来源或账号后停止旧批次。返回页面重置滚动位置，最小窗口仍可访问账号设置与播放控制。
- 默认星夜背景为本项目生成的品牌配图，不是平台封面。没有演示歌曲、虚构推荐歌单或模拟成功的播放功能。

## 实际验证

- `pnpm check`：文档、链接与配置检查。
- `pnpm typecheck`：主进程、preload、契约、测试和 Vue 严格类型检查。
- `pnpm test`：46 项单元测试，包含 IPC 参数拒绝、队列插队不切歌、移除与账号来源隔离。
- `pnpm test:playback`：5 项真实 mpv 集成测试，显式 null 输出；新增 EOF 后自动切到插队歌曲、插队前后同一进程、切歌后唯一进程验证。
- `pnpm test:e2e`：实际 Electron 与 mpv，默认系统输出为 PipeWire。只用合成 PCM WAV 替代原生文件选择结果，验证筛选、多选顺序、下一首不打断、队列移除/清空、展开页暂停与 Esc、定位/恢复、沙箱/IPC、退出清理。
- 1280×800 与 960×640 布局截图已逐张检查，包含主页、本地列表、队列、展开页和设置。截图位于忽略目录 artifacts/，仅含退出状态或合成音频，不含真实账号、二维码、私人歌单或签名地址。早期一次截图遇到 Wayland 捕获时序失败，关闭并行开发窗口、在页面稳定后重跑通过；没有放宽沙箱或安全设置。

检查使用 Corepack 固定 pnpm；缓存写入 /tmp，无全局配置改动。新增依赖 @lucide/vue 1.61.0（ISC，含 Feather MIT 图标），只为实际图标使用；来源见 [依赖记录](../dependencies.md)。

## 尚未验证或实现

此次没有自动登录真实账号，也没有重新宣称两个平台真实账号回归通过。平台歌单视觉布局、权限和多首在线续播仍需用户在官方扫码授权后体验；既有真实接入结果见各平台验证记录。

歌词、平台真实封面、在线搜索、云端创建/编辑歌单、随机/循环、持久音乐库和队列恢复尚未实现。在线取链失败停留并显示原因，不自动跳过或伪装播放成功。本地导入会替换会话队列；关闭应用后队列丢弃。
