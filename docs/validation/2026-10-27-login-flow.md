# 扫码登录保存交互验证

日期：2026-10-27。用户已反馈上一版登录保存正常，本轮按用户要求将全局开关改为二维码区域的按平台选择；该反馈不代表所有平台、发行环境或本轮新交互都已人工验收。

## 行为

- 二维码旁提供“记住登录”，网易云/酷狗独立选择，默认不勾选；成功验证账号后，仅保存已选平台的凭据。
- 未勾选时保留临时登录，下次扫码可重新选择；未完成扫码的勾选不跨应用重启保留。
- 退出平台、取消或重新扫码时撤销该平台选择并删除对应凭据，不影响另一个平台。旧加密或可用性检查迟到不能重新启用保存。
- 已登录时显示“已记住登录”或“仅本次登录”；设置页只保留保存状态、清除入口与可展开的本地保护说明，没有全局开关。
- SQLite/AES 格式不变，保留已有可用记录；启动从实际保存项恢复平台选择，不把旧的空全局开关应用到另一平台。
- preload setRemember 明确接受 provider 与 boolean，运行时拒绝缺参数/未知平台；状态带 revision，UI 丢弃晚到旧状态。

## 验证

Linux 开发机执行 `pnpm typecheck`、`pnpm test`（71 项）、`pnpm test:e2e`（2 项，含构建）与 `pnpm check`。

单元测试覆盖仅已选平台保存、取消勾选不删除另一平台、退出后不能自动再次保存、重启不沿用未完成的选择、迟到加密/勾选撤销。桌面测试通过真实 preload/SQLite 桥接操作设置；二维码选项渲染仅注入明确标识的合成等待状态与 1px 图片，不请求真实二维码、不注入认证成功、不向平台提交测试账号。测试也验证退出酷狗保留网易云选择，关闭/重启后丢弃未完成登录的选择。

实际平台扫码后勾选/不勾选、退出并重登的人工矩阵仍需验收。密钥与数据库同时被读取即可解密的边界不变，见 [凭据说明](../credentials.md)。音频仍使用实际 mpv/PipeWire；不把合成 UI 状态当作平台接入验证。测试结束关闭应用、音频进程和终端命令，不保留真实二维码或私人截图。
