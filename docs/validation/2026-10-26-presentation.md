# 当前歌词、封面与队列修复验证

> 历史验证记录：登录保存随后按用户要求改为本地随机密钥 + SQLite；当前行为与结果见 [SQLite 记录](2026-10-26-sqlite-credentials.md)。

日期：2026-10-26。环境：Linux x86_64、Node.js 24、Electron 45、系统 mpv 0.41.0 / PipeWire；不代表 Windows/macOS 或发行包验证。

## 本次范围

- 队列抽屉改为全部歌曲，与总数一致；区分已播放/当前/待播放，切到最后仍可回选前面的歌曲。“清空后续”仍只删当前项之后。酷狗展示名清理末尾音频扩展名，原 hash 与身份关联不变。
- 凭据保险库增加撤销代次，退出、关闭记住或清除后，迟到加密结果不能重新写入；异步导出后再次核对账号和 generation。保留系统密钥后端限制，未改用明文保存。
- 当前在线歌曲新增独立 presentation 快照。网易云按已登记 ID 取 LRC/专辑信息；酷狗按已登记 hash 查歌词并核对完整曲名，封面来自歌单项或同原 hash 的资源详情。歌词、图片分别失败，不阻断播放。
- 后台限定图片域名、HTTPS、DNS、大小和 PNG/JPEG/WebP 类型，拒绝重定向和 SVG；只将内存数据传页面。没有原图地址、歌词 accesskey、Cookie 或 Token 的公开 IPC。
- 展开播放页以封面/专辑信息与歌词双栏显示，底栏同步当前封面；歌词随实际 mpv 位置高亮，暂停/定位不自建时钟，切歌/停止不显示旧曲内容。没有内容时明确显示缺失提示或原创默认背景。

## 检查与证据

- `pnpm check`、`pnpm typecheck`、`pnpm test`：文档/类型与合成回归；本次单元测试 63 项，含双平台歌词与封面独立失败、未登记 ID、退出时旧结果、LRC 时间/偏移、图片边界和凭据撤销竞态。
- `pnpm test:playback`：实际 mpv、合成 WAV、null 输出，验证播放、试听、定位、切歌与退出；不使用平台账号。
- `pnpm test:e2e`（含生产构建）：实际 Electron/mpv/PipeWire，队列切到末尾仍显示全部项并可回选；仅为歌词/图片渲染注入明确标识的合成 presentation 投影，验证 PNG 解码、暂停、前后定位高亮及 1280×800 / 960×640 布局。测试退出关闭 Electron 与 mpv。
- 显式匿名联网检查用户反馈歌单中的《九万字》公开 hash：取得 50 行带时间戳歌词和有效封面；仅记录数量/可用性，不保存真实歌词、封面地址或响应原文。未使用账号、未播放音频，不代替私人歌单与权限验证。
- 会话总线服务检查：当前未发现 Secret Service 或 KWallet；本机既有 safeStorage 为 basic_text。合成 FakeCipher 已验证双平台保险库重建恢复，但真实加密登录、跨重启/锁定恢复仍未验收。

桌面截图只含生成的音频名、合成歌词和合成图片，保留在忽略的 artifacts/，不提交私人歌单、二维码或媒体地址。

## 待验证与未实现

真实账号下两个平台的不同曲目、无歌词/纯音乐、预览裁剪资源与图片 CDN 兼容矩阵仍需补测；本地标签/内嵌封面、旁置歌词、翻译合并、逐字歌词、歌词缓存和队列跨重启恢复尚未实现。当前只在展开播放页显示行级歌词，未实现桌面歌词。系统密钥持久化需用户在具备已启用/解锁 GNOME Keyring 或 KWallet 的桌面重启应用后验收。
