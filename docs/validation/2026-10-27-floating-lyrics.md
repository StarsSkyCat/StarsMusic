# 悬浮歌词与侧栏交互

日期：2026-10-27。根据用户截图和要求继续调整播放页、左下队列入口与来源导航。

## 变化

- 移除歌词外框、玻璃底色、阴影和顶部说明，歌词直接悬浮于播放背景上；每行水平居中，当前行继续垂直居中。
- 字号同时按歌词区域的宽高计算，宽度限制避免高窄窗口文字过大；行间留白随高度增加。当前行放大/加重，相邻行较清晰，远行逐渐降低透明度并在上下边缘淡出，避免高窗口同时显示十余行。
- ResizeObserver 同时投影可用宽高，保持缩放和定位时当前行跟随；首尾增加足够留白，使首行、末行也能居中。音乐位置与 generation 机制不变。
- 左下会话队列改成单个原生按钮承载整块卡片，数量、说明、边缘均在点击区域内，保留焦点、悬停和键盘 Enter / Space。没有嵌套按钮。
- 本地音乐移入「音乐来源」第一项，顺序为本地音乐 → 网易云 → 酷狗；「音乐库」分组保留音乐库与正在播放。进入本地页、文件选择与返回上下文沿用现有行为。

## 验证

- `pnpm typecheck`、`pnpm check`、`pnpm test:e2e`（含构建）。桌面回归共 5 项，包含实际 mpv / PipeWire、本地播放/暂停/定位、导航、会话与外观恢复。
- 扩展播放舞台回归：双主题、四种窗口尺寸验证无边框/透明歌词区域、文字居中、区域内相交的合成歌词不超过 8 行，以及高窗口字号/行距比最小窗口相应增大。长行仍允许自然换行，不按固定行数裁剪真实歌词。
- 验证小窗口和高窗口队列卡片左上/右下边缘点击、Enter / Space 打开、Esc 关闭后焦点返回整卡；同时确认来源入口顺序。
- 原有当前行中心偏移、主内容无溢出、定位条/下一首可见、缩放不改变 playback generation 的检查继续保留。
- 截图沿用忽略目录 artifacts/listening-light-*.png、listening-dark-*.png，逐尺寸检查暗色与浅色效果；使用合成音频/歌词及原创默认封面，无真实二维码或私人歌单截图。

本次只调整 renderer 与对应回归，没有新增依赖或平台能力。验证限本机 Linux 开发环境；不代表完整可访问性审计、跨 GPU、跨发行版或 Windows/macOS 验收。
