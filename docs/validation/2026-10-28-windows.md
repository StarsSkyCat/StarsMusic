# Windows 适配验证

日期：2026-10-28。Windows 开发适配已启动，安装包与发行验证尚未完成。

## 单元测试基线

- 将桌面设置、控制器和播放记录测试的硬编码 `/tmp` 改为系统临时目录。
- 凭据损坏测试在重新打开数据库前关闭上一实例，避免 Windows 在清除时拒绝删除仍打开的 SQLite 文件。
- 环境：Windows x64、Node.js 24.21.0、pnpm 10.34.9。
- 本机权限执行 `pnpm test`；沙箱会额外拒绝部分重命名、硬链接与删除操作，不据此放宽产品的存储策略。
- 结果：131 项单元测试全部通过，`pnpm check` 与 `pnpm typecheck` 通过。

## Windows mpv

- 使用 mpv 官方 CI 构建 `v0.41.0-dev-gad5877eda`（x86_64 MSVC，2026-10-27 构建），从官方发布页下载，SHA256 对比通过：`00e757c6708430ebd4d56be0a910172aa7d5243a31fdc5044e054aea00badb2f`。文件仅保存在忽略的 `.local/mpv`，不进入仓库或安装包。
- Windows 随机命名管道握手、请求关联、头清理；启动失败和退出均清理进程，子进程不显示控制台。
- `pnpm test:playback`：8/8 通过，使用真实 mpv 与现场合成 WAV、显式 null 输出。覆盖中文/空格路径、解码、暂停/定位/音量/静音、快速切歌、EOF/模式切换、错误与崩溃恢复、合成本机网关与试听限制、暂停恢复及进程唯一性/清理。
- 子进程检查在 Windows 使用 CIM 查询本次测试的直接 mpv 子进程，Linux 仍读取 `/proc`；测试没有用固定成功响应替代真实解码。

上述 null 输出测试不能证明真实扬声器出声。

## Electron 与桌面能力

- 环境：Windows 11 专业版，系统版本 `10.0.26300.0`，x64；Electron 45.0.0。
- 原生托盘对象创建、菜单状态更新、默认关闭退出、可选关闭到托盘、禁用托盘恢复窗口、桌面设置跨应用重启通过。未通过自动化点击系统通知区域图标，图标实际位置/Explorer 重启恢复仍待人工验证。
- 全局快捷键测试比较每项公开绑定状态与真实 Electron `globalShortcut.isRegistered`，禁用后注销通过；合成 runtime 回归另覆盖部分冲突、托盘失败和窗口恢复。系统实体键盘按键仍待人工验收。
- 实际 mpv 使用默认系统输出 `wasapi`，本地 WAV 解码、暂停/定位/静音、播放记录跨应用重启、暂停恢复和退出后 PID 消失通过；静音样本不证明用户听到声音。
