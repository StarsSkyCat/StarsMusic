# 双平台搜索框、账号显示与酷狗权益验证

日期：2026-10-27。环境：当前 Linux x86_64 开发机、Electron 45、Node.js 24；本次不代表 Windows/macOS 或发行包验证。

## 本次修改

- 网易云移除热歌榜入口与前三名舞台，默认进入发现歌单，保留分类、排序、搜索和我的歌单；原榜单后台协议/匿名探测仍保留。
- 两平台共用搜索栏：输入框不再叠加方形焦点边框，焦点提示放在圆角外层；统一字号、间距、按钮，支持 Enter、一键清空和歌曲/歌单切换，清空后保留输入焦点并禁用空搜索。
- 网易云右上角显示实际账号昵称，与酷狗一致；长昵称省略以避免挤出页面。
- 酷狗歌曲搜索、公开详情及私人列表显示平台的 VIP / VIP 音质标记；限免、下载收费和音质收费分开处理，不凭价格、试听或账号会员推断整曲授权。取链后的完整/试听/不可用状态投影到当前列表，保留原 hash-only、编码身份和会话检查。
- 酷狗在登录和恢复后同步标准版会员及独立套餐；音乐空间和账号设置显示已确认权益、有效期、同步状态与重试。未知响应保持失败，不当作无会员；部分失败可保留本次已确认的套餐。每个独立套餐按自己的起止时间过滤，不只读取数组第一项；退出和换账号丢弃旧同步。

## 数据边界

固定协议基线仍为 KuGouMusicApi 1.6.2 / `62730f900dc9fdc51396a663b3d33a6c4c704046`，无新增依赖。权益端点、响应观测和歌曲标记的核对来源见 [酷狗说明](../kugou.md#会员与歌曲收费字段)，协议来源许可见 [第三方声明](../../THIRD_PARTY_NOTICES.md)。只参考字段和观测结果，自行实现，没有复用其他播放器代码或视觉资产。

新增 IPC 为无参数 `refreshMembership`；页面不能提供账号 ID、凭据或任意端点。账号/会员响应仅在可信后台处理，renderer 只获得枚举、时间与归一化错误。无时区的酷狗业务日期按中国标准时间解释；标准版只确认会员标记，不凭等级猜测具体套餐和可播音质。`qvip/dvip` 未确认中文商品名，界面保留代码权益名称。

## 实际检查

- `pnpm typecheck`、`pnpm test`：129 项单元测试，包含收费标记与下载权限区分、多套餐/失效/未来有效期、错误账号、畸形日期、部分失败、同步去重和退出竞态、实际取链权限投影、固定端点与 IPC 白名单。
- `pnpm build` 通过；全量桌面 E2E 14 项通过，覆盖两平台发现、搜索、分类/分页、详情、封面、私人列表、多选/整单命令、账号昵称、会员展示/部分失败、清空搜索与焦点行为。
- `pnpm test:playback`：8 项真实 mpv 检查通过；`pnpm test:desktop`：6 项隔离 D-Bus / MPRIS 检查通过；`pnpm check` 与 `git diff --check` 通过。
- 真实匿名 `pnpm probe:kugou-discovery`：歌曲搜索前两页均 30 首，实际识别 VIP 标记分别为 29 / 30；发现、搜索歌单、详情与封面请求通过。计数为当时响应，不作为固定结果断言。
- 隔离临时配置下真实 Electron 匿名搜索“周杰伦”：网易云 30 首、26 个收费标记；酷狗 30 首、29 个 VIP 标记。浅色 1280px、暗色 960px 截图检查确认搜索框内部无方框、页面无横向溢出、封面和标记可见，无 renderer 异常。
- 合成账号 UI 流程验证已确认/过期/未开始套餐、缺少有效期、部分同步失败、手动同步、账号设置的权益；双主题 960/1280px 搜索截图检查通过。合成数据和命令捕获不冒充真实登录或音频成功。

匿名和合成截图仅保存在忽略的 artifacts 目录，没有采集真实账号歌单或二维码。
