# 酷狗搜索、公开歌单与整单播放

日期：2026-10-27。

## 第一步：后台与窄桥接

- 沿用标准版 App 固定协议基线，新增歌曲搜索、歌单搜索、发现歌单、公开详情分页、登记资源封面和整单播放准备，不加载完整 SDK，不新增依赖。
- 新端点：gateway.kugou.com 的 `/v2/search/song`、`/v1/search/special`（complexsearch 路由）、`/v2/special_recommend`（specialrec.service 路由）和 `/pubsongs/v2/get_other_list_file_nofilt`。字段依据同一固定提交的 search.js、top_playlist.js、playlist_track_all.js；来源和许可见 [第三方记录](../../THIRD_PARTY_NOTICES.md)。
- 匿名可浏览；播放/整单播放继续要求标准版原账号，搜索结果按原 hash 登记和取链，不引入同名替换、网页 Token 或权限推断。公开详情只接受已登记的 global_collection_id；私人 listid 与公开歌单通过明确来源选择，不接受任意请求参数。
- 搜索和详情每页 30，私人整单分页 300；整单最多 10000 首、全部读取成功才替换队列，到实际播放时取链。新请求、退出和切账号使旧搜索、图片与整单准备失效。
- 推荐响应会额外附带卡片，实测请求 30 返回 35；有界保留返回卡片，损坏单条跳过，整页无有效数据时报错。推荐 percount 不作歌曲数量，缺数量保持未知；详情使用实际 count。
- 图片只从已登记元数据按 ID/代次读取，四路并发、32 张内存缓存；沿用 HTTPS、格式/大小/公共地址 DNS/无凭据/不跟随跳转的规则。额外精确允许 c1.kgimg.com，该主机来自匿名推荐封面原响应，已实际 HTTPS 200 下载及栅格校验；没有放行整个 kgimg.com。
- 已通过类型检查、124 项单元测试、构建与原桌面入口回归。显式 `pnpm probe:kugou-discovery` 实际验证发现前两页、歌曲前两页、歌单搜索、公开详情和两类真实封面，只输出归一化计数，不生成二维码、不登录、不保存私人数据。
- 页面接入将在下一步完成。本步不代表真实账号搜索播放、整单取链和免费/会员权限矩阵已验收。

## 第二步：音乐空间页面

- 酷狗入口调整为发现歌单 / 搜索 / 我的歌单，沿用现有音乐空间布局与双主题，使用蓝色来源色。扫码连接统一在账号设置中完成，公开内容不挡在登录界面后。
- 搜索支持歌曲/歌单切换、Enter 提交、前后分页、关键词及搜索类型保留、空结果和错误重试。公开详情可返回搜索/发现；私人详情仍保留筛选及往返播放页的上下文。
- 公开及私人详情“播放全部”调用后台完整准备接口；歌曲行支持播放和下一首，多选倒序插入当前项之后以保持列表先后顺序。这也修正了网易云发现结果多选此前的倒序问题；原网易云收藏/搜索/封面桌面回归保留。
- 发现卡、搜索结果、公开/私人详情及音乐库酷狗卡片均接入封面。抽取共用 PlatformArtwork，缓存/并发队列按平台独立，仍按会话 generation 清理，不共享私人图片；可见性加载和失败默认图保留。
- 新增明确标识的合成 Electron 用例，覆盖匿名播放提示、双类型搜索、分页、缺图/请求失败、合成连接后的播放/整单命令、公私来源区分、多选顺序、私人曲目封面和双主题最小窗口。没有模拟平台认证或音频播放成功。
- 使用隔离临时配置进行实际匿名桌面联网，发现、公开详情、歌曲/歌单搜索及真实封面均显示；浅色/暗色、960px 和 1280px 检查无横向溢出。截图只含公开内容或明确标识的合成数据，位于忽略目录 artifacts/kugou-live-public-*.png 与 kugou-synthetic-*.png。未访问真实用户配置、二维码或私人歌单。
- 已通过类型检查、124 项单元测试、8 项真实 mpv 测试、6 项桌面集成、构建和 14 项完整 Electron E2E、文档及 diff 检查。匿名联网探测通过。
- 未完成：真实账号下搜索曲目出声、整单权限矩阵和跨重启授权验收；收藏/喜欢/歌单创建编辑、会员面板、榜单与分类筛选、跨平台聚合搜索尚未实现；Linux 发行包和其他平台仍未验证。
