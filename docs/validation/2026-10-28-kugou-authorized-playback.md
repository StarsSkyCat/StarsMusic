# 酷狗授权取链与内部文件名

日期：2026-10-28。环境：Arch Linux x86_64、Electron 45、Node 24、mpv 0.41。接续 [文件名误拒](2026-10-28-kugou-filename.md)；本文不把匿名解析或合成授权测试写成本人账号的播放验收。

## 用户补充与观察

用户确认《给你呀》在官方 App 也不可用，不再将其当作本应用独有故障；截图另包含《错位时空》—艾辰的“暂不可用”和《叹郁孤（等什么君）》—宇叔的“权限待确认”，并显示未知歌手。官方 App 可播放其他曲目的用户反馈与本应用未取到资源之间存在差异，应继续排查，不能从匿名状态推断本人账号无权。

- 公开搜索到《叹郁孤》—宇叔，资源详情完整名称为“宇叔 - 叹郁孤（等什么君）”。取链 fileName 是内部 hash 与数字编号，后缀 `.mp`；文件名 hash 与实际返回 hash 是同一资源中不同编码。上一轮仍将编号与歌名作比较，因此误拒。修复后，使用用户提供的完整名称与该公开 hash 验证通过，试听请求明确 `is_full_audio=1`，解析为完整资源。没有下载/播放真实音频。
- 《错位时空》—艾辰本次旧版匿名完整/试听均无地址；补带资源详情的专辑标识也未改变结果，未据此引入未经验证的 album ID 回退。官方授权端点匿名拒绝，无法证明本人登录后的结果。
- 《虞美人》—熙宝的旧版匿名试听有地址、priv_status=0，但没有明确完整标志或试听边界。本轮继续保留该限制，不能把非空 URL 或资源时长当作完整播放许可。

匿名探测脚本只在 /tmp 内使用，只输出受限元数据和布尔结果。没有读取本机真实凭据、私人歌单、保存原始响应/签名 URL 或登录二维码，也没有在仓库保存用户私人歌单截图。

## 实现

1. 内部编号文件名仅接受固定“32 位 hash - 数字编号.音频后缀”格式；文件名 hash 与实际音频 hash 都必须属于按原 hash 唯一匹配的资源编码关系，资源完整曲名仍须匹配。不同基础曲名、明确不同的版本、未映射 hash 或缺失实际 hash 仍拒绝。
2. 云歌单歌手优先使用结构化歌手列表，其次 singername，最后明确文件名前缀；不变更原 hash、歌曲名称、版本或播放来源。
3. 旧完整/试听解析不可用或权限未确认时，增加同一标准版 App 会话的固定官方账号验证 → 单曲授权 → 授权取链。不再将旧接口没有 URL 直接当作所有官方路径不可用。授权失败仍如实报错，不创造会员权限，不使用概念版、网页或其他音源。
4. 临时账号/单曲 auth 只存在本次后台调用，不写凭据持久化、页面或日志；三个新端点均固定 HTTPS。renderer/preload/IPC 未增加通用请求或凭据能力。
5. 一次解析最多补查一次资源详情，即使查询失败也不重发；新增等待点都核对会话 generation 与解析序号，切歌、退出后不会继续使用迟到 proof。最多六次 10 秒网络请求，resolveTrack 后台命令预算从 45 秒改为 75 秒。

协议仅核对既有 MIT 固定基线的 [user_verify.js](https://github.com/MakcRe/KuGouMusicApi/blob/62730f900dc9fdc51396a663b3d33a6c4c704046/module/user_verify.js)、[song_auth.js](https://github.com/MakcRe/KuGouMusicApi/blob/62730f900dc9fdc51396a663b3d33a6c4c704046/module/song_auth.js)、[song_url_auth.js](https://github.com/MakcRe/KuGouMusicApi/blob/62730f900dc9fdc51396a663b3d33a6c4c704046/module/song_url_auth.js) 与文档；按本项目边界独立实现，没有增加依赖或复制参考播放器资产。

## 验证边界

新增合成测试覆盖编号编码关系、错误/缺失 hash、不同曲名/版本、歌手缺失、授权链请求参数与 proof 校验、拒绝授权、试听范围、错误资源和三个授权等待点的切歌/退出。已有实际 mpv 集成改用内部编号文件名的合成资源，并继续检查一秒试听边界。

- `pnpm check`：67 个 Markdown 文件、链接和格式通过。
- `pnpm typecheck` 与 `pnpm test`：严格类型检查、140 项单元测试通过。
- `pnpm test:playback`：8 项实际 mpv 集成通过，内部编号文件名的合成资源仍被限制在一秒试听范围内。
- `pnpm test:e2e`：15 项 Electron 桌面测试通过，实际系统输出 PipeWire。

真实账号的授权链成功、准确私人歌单 hash 与实际出声仍待用户官方登录后复测。本机包更新在完成后记录。
