# 自适应播放舞台

日期：2026-10-27。针对用户截图中播放页下方大量空白的问题，调整播放页尺寸分配；双主题与保存机制已在前一步实现，见 [外观记录](2026-10-27-appearance.md)。

## 修改

- 原播放页只依赖封面/歌词内容高度，歌词又有固定上限；窗口拉高后剩余高度留在下一首下方。现在播放主内容采用可伸展舞台：顶部导航、填满剩余空间的封面/歌词、底部下一首。持续播放控件仍独立位于底栏。
- 歌词面板沿舞台伸展，内部独立滚动。封面和歌曲信息在左侧垂直居中，封面随可用尺寸变化；内容过长时左栏可内部滚动。减少原先整块专辑背景的矩形边界，保留柔和氛围。
- 歌词 ResizeObserver 监听外层可用高度，更新首尾留白并即时居中当前行；避免观测歌词自身 padding 导致缩小窗口后高度无法收敛。居中按实际屏幕几何计算，修正此前不同定位父元素的 offsetTop 相减造成的偏移。
- 文字高亮、播放时间、切歌与歌词 generation 仍来自原有唯一播放状态；主题切换、进出页面、窗口缩放不推进播放 generation。减少动态效果偏好使用即时定位，离页后断开尺寸监听。
- 更窄视口保留纵向可滚动布局，原生窗口下限仍为 960×640。

## 验证

使用本机 Linux、Electron 45 与实际 mpv / PipeWire，采用固定 pnpm 10.34.9。

- `pnpm typecheck`：Node / Vue / 测试严格检查。
- `pnpm check`：文档与链接检查。
- `pnpm test:e2e`（含构建）：5 项；新增播放舞台回归使用实际合成 WAV 播放/暂停，仅歌词采用明确标识的合成投影，不登录平台或模拟音频成功。
- 新增矩阵同时覆盖浅色与暗色的 960×640、1280×800、1240×1260、1440×1000，验证主内容无横向/纵向溢出、歌词面板与下一首间距不超过 24px、下一首位于内容底部、定位条保持可见。1240×1260 的歌词面板超过 800px 高，填充此前未利用空间。
- 缩放后当前行中心偏移小于 4px，暂停定位、减少动态效果及再次进入均保留歌词跟随；两主题和所有尺寸切换后播放 generation 不变，无页面异常。
- 检查 artifacts/listening-light-tall.png、listening-dark-tall.png、两主题 listening-*-minimum.png / listening-*-desktop.png。图片为既有原创默认封面，文本明确标识为合成布局验证。另检查隔离匿名配置下两主题的音乐库、平台连接、空队列和空播放页（palette-*.png）。

前一步 75 项单元测试验证凭据、播放/接口边界与新增主题存储；本步没有改动这些后台逻辑。没有新增依赖，也不读取/保存真实二维码或私人歌单截图。全部截图位于忽略目录 artifacts/，临时 Electron 与配置在结束时关闭/清理。
