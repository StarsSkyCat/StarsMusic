# Liquid Glass 全页面重设计

日期：2026-10-27。按用户要求使用 UI UX Designer 的重设计与设计落地方法，在现有 Electron / Vue 应用中实现。目标是 Linux 桌面音乐播放器；不是单独网页、静态提案或新平台能力。此前的石墨黑 / 雾紫布局保留为历史验证记录，本记录描述当前视觉。

## 设计与实现

| 原界面问题 | 当前改动 | 操作目的 |
| --- | --- | --- |
| 固定矩形侧栏、底栏连成平面 | 悬浮侧栏与独立底部播放舱，主内容独立滚动 | 导航、浏览和播放层次清晰 |
| 首页缺少视觉重心 | 非对称标题、原创折射唱片、当前歌曲胶囊 | 建立音乐空间，同时保留导入和连接入口 |
| 来源卡外观相近 | 本地薄荷、网易云柔粉、酷狗冰蓝，显示真实连接状态 | 清晰区分入口和账号状态 |
| 登录、列表和歌词沿用相同面板 | 账号双卡、平台连接步骤、玻璃歌单封面、歌曲图标、封面舞台与歌词分栏 | 每个任务有独立的布局重心 |
| 按钮和抽屉缺少统一材质 | 薄荷主操作、玻璃次操作、图标按钮、悬浮队列、统一焦点及禁用状态 | 可预测的操作优先级与反馈 |

覆盖音乐库、本地音乐、网易云/酷狗来源页、扫码区域、歌单卡片/详情、账号与设置、登录保存/诊断、播放空状态、封面/歌词页、播放队列、选择条、错误与提示，以及持续显示的底栏播放控件。

GlassScene.vue 只包含装饰节点，使用渐变、同心纹、透视、轨道与玻璃珠绘制原创唱片，整体从辅助技术隐藏。没有读取音频、伪造实时频谱或展示虚构歌单。既有默认星夜背景仍用于没有真实封面的播放页。没有新增依赖、远程素材或改动 main/preload/Provider/数据库边界。

## 视觉约定与状态

- 深海底色 `#09151b`，主文字 `#edf7fa`，辅助文字 `#9badb6`，薄荷强调色 `#a5f3df`，主按钮深色文字 `#103b37`。
- 以系统中文字体栈、8px 间距基准和 24px 主要面板圆角组织内容；紧凑列表与胶囊按用途调整。首页使用较大标题，列表保留歌曲、歌手、来源与时长。
- 玻璃采用半透明多层渐变、边缘高光、内阴影及局部背景模糊。模糊集中于侧栏、播放舱、队列和浮层；背景光场静态，不使用持续粒子或指针跟随。
- 主要按钮、次要按钮和图标按钮提供悬停、按压、键盘焦点与禁用状态；队列打开有短暂过渡。`prefers-reduced-motion: reduce` 禁用动画、过渡和装饰位移；歌词沿用原有减少动态效果下的即时定位。
- 新增「跳到主内容」键盘入口，导航用 `aria-current` 标识当前页面。二维码保持实心白底，不对其内容做玻璃模糊；记住登录、取消、退出与错误继续由真实快照驱动。
- 960×640 下压缩侧栏辅助内容，播放、定位和下一首卡片仍可用；更窄宽度保留图标导航、纵向来源卡和歌词布局。当前支持的原生最小窗口仍为 960×640。

## 验证

在本机 Linux、Electron 45、Vue 3、mpv / PipeWire 环境验证。使用项目固定 pnpm 10.34.9（`COREPACK_HOME=/tmp/starsmusic-corepack corepack pnpm`），避免本机 pnpm 启动器只读缓存锁；没有修改全局配置。

- `pnpm setup:electron`、`pnpm build`：通过；E2E 命令也重新构建了全部产物。
- `pnpm check`：48 个 Markdown 文件及配置、相对链接检查通过。
- `pnpm typecheck`：Node / Vue 严格类型检查通过。
- `pnpm test`：71 项通过。
- `pnpm test:e2e`：3 项通过，包含实际 mpv 解码与 PipeWire 输出、播放/暂停/定位、筛选/多选插队、队列管理、歌单往返、旧列表隔离、记住登录选择隔离、应用重启与退出清理。
- 增加键盘 Tab →「跳到主内容」→ Enter 焦点回归；1280×800、960×640 下侧栏设置按钮不越出面板；两个尺寸下播放页下一首卡片保持可见。
- 逐页检查音乐库、本地曲目、双平台连接、账号设置、合成扫码区域、合成歌单卡片/详情、默认封面/合成歌词、空播放页和空/非空队列截图。补查 1440×1000 首页及 600×800 CSS 窄视口，无主内容横向溢出；窄视口不改变应用原生最小窗口限制。
- 额外隔离匿名配置的截图检查验证 `prefers-reduced-motion` 下队列无动画。额外截图使用 Electron X11 渲染后端；这不代表完成独立 X11/Wayland 桌面与发行包矩阵。

截图保存在忽略目录 artifacts/，包括 liquid-glass-library.png、liquid-glass-settings.png、liquid-glass-netease.png、liquid-glass-kugou.png、liquid-glass-empty-player.png、liquid-glass-queue.png、liquid-glass-library-minimum.png、liquid-glass-settings-minimum.png、liquid-glass-narrow.png，以及明确命名为 liquid-glass-synthetic-* 的合成扫码/歌单投影；既有 E2E 也生成本地播放、默认封面和歌词截图。合成投影不模拟平台请求或音频成功。测试和截图检查结束后关闭临时 Electron 并清理临时配置，未向仓库加入账号数据或截图。

真实平台登录由用户在官方 App 中完成，自动化不获取或保存真实二维码、凭据及私人歌单。

## 未完成与限制

本轮只重设计应用内界面，没有增加在线搜索、目录扫描、循环/随机、实时音频分析或跨重启队列。两个平台的完整权限矩阵、真实账号跨重启验收、Linux 安装包、发行版/桌面矩阵以及 Windows/macOS 仍按原路线图待办。

没有完成跨 GPU 的模糊性能基准或完整 WCAG 审计；视觉检查和本机桌面结果不能替代发行验证。系统原生文件选择器由 Linux 桌面环境提供，沿用原生样式。
