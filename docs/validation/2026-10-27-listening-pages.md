# 独立播放页与音乐导航验证

日期：2026-10-27。用户要求重新梳理页面，让歌词使用独立播放页面。Linux 开发环境，Electron 45、Vue 3、实际 mpv / PipeWire；不代表其他系统或发行包验收。

## 页面与操作

- 音乐库首页使用紧凑布局，集中展示本地导入、音乐来源、平台歌单与当前歌曲“继续聆听”；去掉占据首屏的大幅装饰横幅。继续聆听会恢复已暂停歌曲并进入播放页。
- 侧栏新增“正在播放”，底栏封面也可进入。独立页面替换主内容，不使用 dialog/backdrop；侧栏、账号入口和底栏持续可用。封面/来源/专辑与歌词分栏，底部显示下一首并可打开完整队列。
- 底栏保留唯一一组播放控件，切页不重建播放器、不推进播放 generation。无当前歌曲时展示明确空状态和返回选歌入口。
- 返回按钮、底栏封面或 Esc 返回原浏览页，保留来源、歌单、筛选、多选和滚动位置。打开队列时 Esc 先关闭队列，不离开播放页。
- 歌单详情直接显示曲目，提供“返回全部歌单”；切换歌单时按 ID 隐藏旧曲目，避免新标题下短暂展示另一歌单内容。平台只读，不增加创建/编辑或假搜索。
- 歌词初次打开也定位当前行，包含暂停时重新进入的情况。实际封面失败时使用现有原创星夜背景；没有复制参考播放器的视觉资产或引入新依赖。
- 账号页把平台登录放在前面，记住选项位于二维码区域；应用版本/运行信息收起在“应用信息与诊断”，减少日常操作干扰。

## 执行检查

- `pnpm check`：文档链接、格式与配置。
- `pnpm typecheck`：Node/Vue 严格类型检查。
- `pnpm test`：71 项，包含此前已提交的按平台保存、退出删除、取消及迟到勾选保护。
- `pnpm test:e2e`（含构建）：3 项通过。主桌面仍使用实际音频解码与默认 PipeWire 输出，验证无播放弹窗、独立页入口/空状态、导航返回不改 generation、筛选保留、歌词定位/再次进入、队列 Esc 顺序与应用退出。
- 检查 1280×800 和 960×640 截图，验证封面、歌词、下一首卡片与底栏控件可见，小窗口主内容无横向溢出。图片/歌词缺失时页面可继续操作，减少动画偏好仍生效。
- 歌单导航回归以明确标识的合成只读 UI 投影验证详情/卡片切换和旧曲目隐藏，不认证、不模拟平台请求成功、不播放合成平台地址。二维码选项测试同样只注入合成等待状态和 1px 图片，不读取/保存真实二维码或私人歌单。
