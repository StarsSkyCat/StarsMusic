## 负向与竞态检查

- 数字 ID、未知平台、混用平台渠道、本地账号字段、非法 generation、缺少账号或验证信息的 connected 状态被拒绝。
- 缓存键分别区分平台、账号、渠道、游客与字符串账号，不因相同平台 ID 跨平台合并。
- 本地资源/曲目类型错配、文件 ID 不匹配、无效试听区间、非有限音质参数被拒绝。
- HTTP/file 协议、URL 内嵌身份/片段/控制字符、请求头注入、冲突头和传输控制头被拒绝。
- 未知错误及伪造平台错误不透传原始文案；已核实分类使用本地固定错误描述。
- 手动控制 Promise 完成顺序：旧账号请求忽略取消且晚返回时，旧缓存与新账号缓存都不会被旧回调写入；旧错误同样丢弃。
- 退出重登同一账号、切换酷狗渠道均取消旧 signal；过期租约不会开始新请求；退出酷狗不取消网易云。
- 伪造/不同守卫的租约被拒绝；abort 同步监听器重入产生的新会话不会被外层 activate 覆盖。

测试全部使用合成上下文和资源描述，不保存账号、Cookie、Token、签名 URL 或原始平台响应。
