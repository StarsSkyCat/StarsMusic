## 操作与实际结果

1. `node --experimental-strip-types scripts/probe-kugou.ts`：匿名调用设备注册、二维码挑战和首次轮询。结果通过，设备注册与“等待扫码”状态可达；没有登录账号，未输出设备标识、key、二维码或原始响应。
2. 文档检查、严格类型检查和应用构建通过；构建产物同时包含 `index.js`、`netease-worker.js` 和 `kugou-worker.js`。
3. 单元/边界测试共 37 项通过，其中酷狗新增 10 项：具体 IPC 参数、快照投影、扫码状态、账号一致性、旧二维码/旧账号/旧歌单响应丢弃、过期、SSA、大页/字符串字段容错、hash-only 取链、试听文件名匹配、媒体主机隔离与试听边界。
4. 实际 mpv 集成测试 4 项通过；扩展的合成酷狗资源经 loopback 网关解码、平台隔离、试听上限和清理检查，使用 null 输出与合成音频。
5. 桌面 E2E 通过：实际启动酷狗 utilityProcess，验证匿名 `getState`、本地退出、preload 白名单和页面“连接酷狗”入口；沿用本地音频的真实 PipeWire 输出。没有自动生成真实二维码或截图。
6. 真实账号操作：用户扫码并确认授权，应用进入已连接；用户反馈“登录成功，歌单获取成功”。未记录昵称、账号 ID 或私人歌单内容。
7. 用户打开歌单时，曲目列表显示“服务返回了无效数据”，未进入播放。按实际反馈检查响应兼容性：合成用例原先只覆盖 50 条以内、数字时长和带 `count` 的响应，真实云歌单可能返回更大的页、缺失总数、字符串时长/数量，或夹带无法解析的单条记录。
8. 修正解析策略：曲目页改为 300 条；缺少 `count`/`total` 时按实际条数判断下一页；接受十进制字符串形式的时长/数量；兼容 `audio_id`；跳过单条损坏记录但整页无可用曲目时仍报错。新增 300 条大页、缺失总数、字符串时长和损坏单条的合成测试。
9. 用户重新扫码复测：曲目列表已显示，说明第 8 项修复覆盖了真实响应；点击曲目播放时界面显示“服务返回了无效数据”，播放条没有进入加载或播放。该错误出现在后台取链/媒体 URL 校验阶段，不是歌单解析。
10. 扩展媒体主机白名单并加入仅由 `STARSMUSIC_DEBUG=1` 启用的安全诊断，只输出媒体主机、字段名、hash 前缀、时长和权限字段，不输出完整 URL、签名、Token、账号标识或歌曲名。
11. 用户复测确认**播放成功且实际出声**；同时反馈部分歌曲显示名称与实际听到的音乐不一致。诊断显示这些曲目取链返回的 `hash`/`std_hash` 与登记 hash 不同，且返回时长与登记时长不一致（例如登记 207 秒、返回 254 秒）。
12. 进一步核对确认：云歌单里的 `album_id`/`album_audio_id`/`audio_id` 与主 hash 可能错配；取链带上这些 ID 会被平台带到另一首歌，这是“名称与声音不一致”的直接原因。改为只按主 hash 取链（`album_id`/`album_audio_id` 固定 0），并保留返回文件名、时长与登记曲目的匹配校验。
13. 用户复测：之前名称与声音不一致的歌曲不再出现 `track-mismatch`；其中可授权的曲目按返回的编码正常解析，部分曲目返回 `status=3` 或 `error_code=35104`，提示无权/资源不可用。这些是平台曲目权限或目录限制，不是取错歌曲；应用没有播放错误音频。
14. 真实曲目：登录、歌单列表、曲目列表和部分曲目出声通过；部分曲目按平台响应不可用。Token 作用域、试听/会员/购买/下架矩阵、链接过期恢复和不同音质仍未分别验收。

本机 pnpm 入口受只读 HOME 限制，实际使用 `node_modules/.bin` 与 `node --test` 执行等价命令；这是本次代理环境的限制，不改变仓库标准命令。

## 安全与隐私

测试只使用明确标识的合成账号、Token、哈希和媒体地址；仓库、日志和截图未写入真实凭据、账号 ID、个人歌单或签名媒体 URL。真实账号反馈只记录阶段结果和脱敏的 hash 前缀/时长。设备身份在后台进程内随机生成，注册载荷不采集硬件/传感器信息；临时凭据不落盘。调试输出仅在 `STARSMUSIC_DEBUG=1` 时启用，且不包含完整签名地址或歌曲名。

## 结论与后续

酷狗已具备可重复的“官方 App 扫码 → 账号验证 → 私人歌单/曲目列表 → 部分歌曲实际出声”路径，P0 第 5 项可按“受限通过”记录；但不能据此宣称酷狗全部曲目可用。导致“名称与声音不一致”的根因是取链附带可能错配的云歌单 album/audio ID；改为只按主 hash 取链后，不再播放错误歌曲。部分曲目仍返回 `status=3`、`35104` 等平台限制并显示不可用，这是平台目录/权限差异，不是登录成功即可播放。后续需分别记录免费、会员、购买、试听、下架和不同音质矩阵，并验证 Token 刷新与链接过期恢复。网页登录仍未实现，不能写成已验证渠道。
