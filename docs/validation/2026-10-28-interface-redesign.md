# 全界面重设计与材质分层验证

日期：2026-10-28。环境：本机 Linux / niri Wayland 会话、Electron 45.0.0、Vue 3.5.44；所有自动化使用独立临时用户目录，不读取真实账号。

## 设计依据与改动

本次在实际运行的旧版界面上截图检查，覆盖浅/暗音乐库和设置。旧版内容、来源卡、侧栏、账号卡都叠加相近的渐变、阴影与细描边，层级区分不清；音乐库 CSS 唱片占据较大空间，正文和操作说明字号偏小。

参考 [Apple Materials 指南](https://developer.apple.com/design/human-interface-guidelines/materials) 对内容层与浮动导航/控制层的区分，调整为：

- 音乐库：独立标题、实际本地曲目/已同步歌单数量、已有原创山景背景、紧凑来源入口和继续聆听按钮。删除旧 GlassScene.vue 唱片、轨道与玻璃珠；山景只是装饰，不是推荐歌单或平台封面。
- 全局框架：中性浅/暗底色，红色主操作与蓝色酷狗来源；侧栏、工具栏、播放条和浮层采用背景模糊、饱和度、细边缘高光与柔和阴影。内容卡、曲目列表和设置使用稳定底色。
- 平台空间：页头直接显示平台名称，统一分段导航、封面圆角、搜索和列表；移除倾斜封面和多余叠层，保留自建/收藏类型、费用、会员有效期、同步失败及重试信息。
- 播放：封面端正展示、歌词当前行使用高对比正文色，保留原有歌词居中与高度缩放；播放模式移到上一首左侧，并同步调整 DOM 顺序，保持键盘顺序与视觉一致。
- 设置与队列：外观、桌面能力、账号及凭据使用同一分组表面；队列仍为原生 dialog，保留键盘关闭与焦点返回。修正文案中不准确的固定“顺序播放”。
- 可访问性：保留原生单选框、按钮、导航状态、焦点与禁用行为；减少动态效果时取消动画，减少透明度或不支持背景模糊时改用实底。二维码继续使用实心白底。

这是 Electron/CSS 的跨平台视觉实现，不等同于 Apple 原生 Liquid Glass；未实现原生光学折射、桌面墙纸采样或系统材质 API。没有新增依赖、字体或外部图片，没有修改 IPC、Provider、凭据和音频服务。

## 自动化检查

- `pnpm setup:electron`：固定 Electron 运行时可用。
- `pnpm typecheck`、`pnpm build`：通过。
- `pnpm test`：142 项通过。
- `pnpm test:e2e`：17 项通过（41.2 秒）。
- `pnpm check`：69 个 Markdown 文件及配置检查通过；`git diff --check` 通过。

既有 E2E 验证实际 Electron / mpv / PipeWire 播放、MPRIS 模式、队列重启恢复、窗口控制、外观重启恢复、音量拖动、歌词高度与居中。双平台浏览/搜索/收藏使用明确标记的合成 UI 响应，未登录真实账号、未把合成流程算作平台验收。

新增 interface-design.spec.ts 使用明确标记的合成长歌名投影，检查两套主题、960×640 / 1440×900 的音乐库、本地音乐、播放页和设置，验证横向溢出、底栏遮挡、首页按钮相交、队列键盘关闭与焦点返回。使用 Chromium 媒体偏好模拟减少透明度和减少动态效果。

初轮回归发现播放模式按钮只用 CSS 排序导致 DOM/视觉顺序不一致，现已通过组件节点排序修正。视觉检查发现酷狗搜索按钮继承全局红色，已恢复平台蓝色。新增测试修正了对空白 flex 区域的误判及带数量导航的定位方式。
