# 音乐库全来源搜索与酷狗收藏排序

日期：2026-10-27。环境：当前 Linux x86_64 开发机、Electron 45、Node.js 24；没有验证其他操作系统或发行包。

## 酷狗“我喜欢”的顺序

根据用户对官方客户端的核对，私人接口的默认返回方向与“我喜欢”显示方向相反。本次按 `love` 分组或本人默认 `listid=2/type=0` 识别收藏列表，完整读取后统一反转，再按 300 首分页给界面；整单播放采用相同顺序。普通歌单、收藏他人歌单和公开歌单不跟随反转。

不对各页单独反转，避免 300 首以上时把最新收藏留在后页。完整读取有 10000 首上限，缺页/请求失败不能返回局部成功；登录代次、退出和换列表保护继续有效，退出清空排序缓存。首次打开或刷新重新读取，后续分页使用当前会话的同一列表快照。worker 的详情读取等待上限为 120 秒，与完整歌单准备一致。

固定协议端点及来源保持原样：[playlist_track_all_new.js](https://github.com/MakcRe/KuGouMusicApi/blob/62730f900dc9fdc51396a663b3d33a6c4c704046/module/playlist_track_all_new.js)。没有添加未经确认的排序参数，没有更改取链和权限检查。合成 650 首回归验证全局首尾、两处跨页、普通歌单、整单顺序一致性，以及退出后的迟到结果、不完整收藏列表失败；真实账号与官方客户端逐项核对仍待用户验收。

## 音乐库与搜索

- 首页移除“当前播放队列”曲目列表，保留继续聆听卡、底栏和队列抽屉；移除界面区域不会清空播放队列。
- 顶部改为明确的全来源搜索框，按 Enter 或搜索按钮后同时搜索网易云/酷狗；输入过程中不逐字联网。支持歌曲/歌单切换、清空、来源计数和快速跳转。
- 每个平台独立显示加载、失败、空结果、重试与分页；单个平台失败不吞掉另一个平台的结果。快速换词丢弃旧结果，清空返回音乐库概览。
- 歌曲结果同步匹配已加载本地音频；歌单结果同步匹配已同步私人歌单名称。没有声称索引所有本地文件，或远程搜索私人歌单里的全部歌曲。
- 播放和多选下一首按结果来源调用现有白名单方法；同名歌曲、平台 ID 与本地队列 ID 不混用。在线浏览可匿名，播放前仍需连接对应账号；有序批量插队保持结果先后。
- 公开歌单结果进入对应平台详情，私人歌单结果进入私人列表。往返正在播放页保留关键词、类型及未失效的分页结果；原本地/私人详情筛选保持在各自页面。

实现位于 renderer 的 LibrarySearch.vue 与 App.vue，后台复用两平台已有 browse/getArtwork/播放命令；没有增加任意请求 IPC、新依赖或账号写入。平台状态按既有 generation/revision 校验，凭据不进入 renderer。
