# 网易云会员兼容、整单播放与收藏编辑

日期：2026-10-27。根据用户报告修复权益同步无效数据、整单播放，并增加喜欢/自建歌单编辑/收藏发现歌单。

## 第一步：会员响应兼容

上一版把 userId、vipCode 和数值到期日都当作必填，无法处理省略账号/代码、字符串时间或 App 端只返回 rights 的合法变体。现在返回账号时仍严格匹配，但缺省账号使用后台已绑定的当前账号请求；兼容明确 rights 与可缺省到期日，不制造会员等级或到期日。Web 响应无法解析时再请求固定 App VIP 端点，网络/认证错误不静默换端点。

这是响应兼容回归，尚未拿到用户实际登录响应，不能认定已复现其账号的确切失败字段。不要求粘贴凭据或会员原始响应。

增加 App 回退后，会员命令最多三次固定请求，客户端超时相应为 45 秒，单个网络调用仍限制 10 秒。

## 第二步：整张歌单播放

公开详情的“从第一首听起”和网易云私人详情的“播放全部”读取整张歌单 trackIds，最多 10000 首，详情每批最多 1000 首、两路加载并按原顺序归并。未完整读到详情时不清理原队列，不把单页冒充整单。完成后原子替换本次队列，从首曲开始；后续歌曲按播放进度才取签名音频。旧账号或新的播放选择会使旧准备结果失效。10000 首以上明确拒绝，不静默截断。

补充合成服务 1300 首归并、跨页顺序、未登记 ID 与退出竞态测试，以及真实播放器类 350 首队列/惰性解析回归；不模拟音频成功。页面回归确认按钮转发整单命令而非首曲命令。

## 第三步：喜欢、编辑与收藏

- 喜欢 ID 在当前账号后台读取，歌曲菜单提供红心切换。自建歌单添加弹窗排除喜欢列表与其他账号所有的歌单；移除只在自建/喜欢列表显示，喜欢列表使用取消喜欢端点。公开歌单收藏在详情操作，可在我的歌单查看。
- 写入前重新验证歌单所有者，资源必须已登记。固定端点返回成功后回读验证；读后未确认不提示成功，写入可能已发送时明确提示核对。未实施服务器写入的乐观成功状态，不自动重复写入。
- 写入串行、旧账号与旧分页/喜欢回读丢弃；网络错误保留未确认状态，明确安全验证错误保留为验证要求，认证过期清理会话。原始响应与凭据不进入 renderer、日志或测试截图。
- 固定协议字段参考同版本的 like.js、likelist.js、playlist_tracks.js、playlist_subscribe.js。未引入该 SDK 或新依赖，也未复制反检测环境或静态安全令牌。真实服务可能要求官方安全验证，不能把合成写入回归当作该验证链已完成。

最终检查：类型检查、99 项单元测试、7 项含构建桌面回归、文档与 diff 检查。新增 UI 用例只注入明确标识的合成收藏数据，捕获喜欢/增删/收藏联合命令，检查自建歌单选择、非所有者无移除入口、保存后状态及双主题最小窗口；实际音频状态保持 idle。截图 artifacts/netease-library-synthetic-*.png 仅为合成回归，不是真实私人歌单。

尚未完成：用户报告账号的确切会员响应实机复现，以及真实账号的喜欢、自建歌单写入/删除、收藏安全验证与整单在线出声验收。本次没有在用户账号自动执行外部写入、读取其持久凭据或请求粘贴响应。
