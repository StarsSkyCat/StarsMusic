# 0002：网易云临时后台会话与媒体网关

日期：2026-10-26。状态：已采纳；本次用户扫码、歌单和实际出声通过，完整权限及发行验证仍待补充。

## 背景

首个在线平台需要一条可重复的登录与播放路径，同时遵守无凭据落盘、无原始响应日志、无任意请求桥接及平台会话隔离规则。审查 api-enhanced 4.41.1 发现默认入口会创建共享临时令牌文件，传输失败可能打印完整响应；直接载入完整 SDK 也会引入本阶段不使用的服务端与解锁模块。

## 决定

以 4.41.1 固定提交为协议基线，仅用 Node crypto/fetch 实现需要的白名单端点，并保留原 MIT 来源声明。唯一新增应用依赖为实际使用的 qrcode；不引入完整 API SDK、不运行公开 HTTP API 服务。

平台请求及 Cookie 放入 Electron utilityProcess 内存，默认临时登录；主进程负责窄消息协调，页面只收公开 DTO 和短时二维码图。取消、切账号、后台崩溃和退出均使旧会话失效；主进程公开 generation 跨后台重启保持递增。utilityProcess 不被视为无权限安全沙箱。

媒体采用随机令牌保护的 loopback 网关，将真实签名 URL 留在后台，逐跳校验网易云 CDN 与 TLS，只转发 Accept/Range。兼容本机 198.18.0.0/15 Fake-IP DNS 代理，避免把正常代理映射误判为内网攻击；主机白名单、TLS 和其他私网限制保留。播放器继续每首创建独立 mpv，旧实例退出后再启动新实例。

## 备选与影响

直接加载 SDK 更省适配代码，但默认文件、日志和依赖边界不符合当前要求；外部公开 API 服务增加部署与凭据流转，本阶段不选。直接把签名媒体地址交给 mpv 无法由应用逐跳验证媒体重定向，因此选本机网关。

薄适配器需要独立跟踪上游协议变更，不能把 SDK 的所有接口能力当作本项目已实现。当前只验证固定端点与本次账号闭环；没有记住登录、完整权限矩阵或全部音质，平台升级、IPv6/代理及发行渠道仍需回归。
