# ADR 0001：Linux 优先的模块化桌面架构

- 日期：2026-10-26
- 状态：采用技术方向；实际版本、接口渠道和分发能力等待 P0 验证。

## 背景

需要一款 Linux 优先的跨平台音乐播放器，同时连接网易云与酷狗。参考项目使用 Electron，相关社区接口主要基于 Node.js。Linux 的桌面、显示协议和发行版差异需要作为首版约束。

## 决定

采用 Electron + Vue 3 + TypeScript。mpv 独立进程承担音频，SQLite 保存本地数据。Provider、播放、存储与系统集成分离；公共契约不依赖具体桌面框架。

两个平台独立维护登录与渠道，统一实体、搜索呈现和队列。UI 不接触凭据或直接访问私有平台接口。后台播放服务维护唯一状态源。

当前先建立文档和仓库工具，不提前安装全部业务依赖，也不实现无验证基础的登录成功界面。

## 备选与影响

Tauri 的系统 WebView 可减少运行时打包负担，但需额外验证 WebKitGTK 差异与 Node 接口承载；Qt/Flutter 需要更多网页登录和接口桥接工作。Electron 接受体积、内存与安全更新成本，以换取一致的 UI 运行环境及接口生态。

mpv 增加外部二进制、依赖与许可管理工作；独立进程减少 Electron ABI 耦合。不能直接把 mpv 输出接入浏览器 Web Audio，实时频谱与沉浸特效单独规划。

## 验证与重审条件

按 [P0 计划](../roadmap.md) 验证真实账号、音频、凭据与安装包。若 mpv 分发或某平台登录渠道无法满足首版目标，记录实测证据并形成新 ADR。详细方案见 [产品设计](../design-and-architecture.md)。
