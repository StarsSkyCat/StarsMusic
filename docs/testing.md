# 测试与验收

## 命令与边界

| 命令 | 实际验证 | 环境 / 不代表的能力 |
| --- | --- | --- |
| pnpm check | 必需文件、MIT 元数据、JSON、Markdown 内联相对链接、围栏与行尾 | 只需 Node；不检查外部链接、锚点、引用式链接或 YAML 语法 |
| pnpm typecheck | 应用和测试的 TypeScript / Vue 严格类型 | 不证明运行时成功 |
| pnpm test | IPC、领域契约、会话竞态、平台投影、凭据与队列等合成回归 | 不访问平台、不登录真实账号 |
| pnpm test:playback | 真实 mpv、本地 / 网关合成 WAV、定位、试听、切歌与退出清理 | Linux / Windows + mpv；null 输出不能证明扬声器出声 |
| pnpm test:desktop | 真实 MPRIS / mpv 与隔离 D-Bus；portal / 通知协议使用合成服务 | 仅 Linux + dbus-run-session + mpv；不等于真实桌面授权或图标可见 |
| pnpm test:e2e | 实际 Electron / mpv、沙箱、IPC、UI、存储与默认系统音频输出 | 需图形和音频会话；另一平台的专属用例明确跳过 |
| pnpm test:package / pnpm test:package:win | 独立运行目录的音频、沙箱、后台、进程和恢复检查 | 必须先构建相应本机包；不能代替全部系统矩阵 |
| pnpm test:installer:win | 临时中文 / 空格路径下真实安装、运行、卸载、默认应用数据与注册项检查 | Windows；拒绝覆盖既有安装或用户数据；只创建合成数据；不验证签名或跨版本升级 |

E2E 仅替换原生文件选择器交互，不模拟音频播放；界面测试使用明确标识的合成歌单。临时用户配置独立于真实账号，截图留在忽略的 artifacts/，不需要下载 Playwright 浏览器。数量以实际运行输出为准。

## CI

[仓库检查工作流](../.github/workflows/checks.yml) 在 Linux 执行离线文档检查，在 Linux / Windows 执行冻结安装、类型、单元测试和构建，Linux 另执行 mpv null 输出集成测试。配置存在不表示远端某次运行已通过；CI 没有真实账号、图形桌面、安装包或系统音频验收。

匿名 probe 命令显式联网，不在 CI 执行，不输出二维码或原始响应；成功仅说明该次匿名端点可用。真实登录、会员权限、写入和听音需用户在官方流程中验收。

设置页移除诊断及登录管理，平台页首提供账号、会员与扫码/退出；Linux 实际 Electron 验证登录保存选项隔离、双主题布局、平台搜索和桌面开关。凭据删除沿用已覆盖的按平台删除与迟到写入防护。Arch 清理回归使用临时主目录和复制的合成进程，验证进程归属、配置/密钥/队列/缓存删除、音乐文件保留、符号链接边界，以及钩子账号筛选和降权调用；不执行真实账号删除。SIGTERM 测试使用真实 Electron/mpv 与合成音频。

本机执行 `pnpm check`、`pnpm typecheck`、`pnpm test`（146 项）、`pnpm build` 和完整 Playwright E2E（18 项通过，1 项 Windows 专属跳过）；`pnpm package:arch` 与 `pnpm test:package` 通过，包内卸载钩子及清理脚本与源码一致。Wayland / X11 独立包使用 PipeWire 与 MPRIS；XWayland 宿主仍忽略原生最小化/最大化。独立包在临时 HOME 启动并播放合成音频后，经清理脚本验证默认 SQLite 目录删除、mpv 退出及原音频保留；这仍不等于实际 pacman 删除事务。

新 Windows 卸载配置和测试脚本已更新，当前 Linux 环境未运行新版 Windows EXE 安装/卸载。Arch 完整 pacman 删除事务尚未实测；历史安装记录不代表本次清理行为已验收。

## 变更验证

文档变更执行 pnpm check；逻辑变更增加或运行能验证行为的测试。涉及 IPC、会话、媒体或存储时覆盖无效输入、旧响应、切账号 / 切歌及退出清理。安装包变更需验证独立运行和许可文件，不只检查源码构建。

PR 说明实际执行的命令、环境和未执行原因；真实账号、其他系统、签名或公开发行未完成时明确列出，不用 Mock 或跳过标为通过。
