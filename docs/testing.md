# 测试与验收

## 当前检查

```bash
pnpm check
pnpm typecheck
pnpm test
pnpm test:playback
pnpm test:e2e
```

check 检查脚本语法、仓库必需文件、JSON 配置、Markdown 内联相对链接、代码围栏及行尾格式。不校验链接锚点、引用式链接或 YAML 语法，不访问外部链接，不验证第三方接口、登录、音频或桌面兼容性。

typecheck 使用 tsc 与 vue-tsc 检查全部应用及测试源码。test 使用 Node 内置测试器，覆盖其他窗口/子帧/变更文档/额外参数被拒绝、开发地址限制和后台响应校验。

当前共 35 项单元/边界测试：原有 IPC、领域契约、会话守卫和播放快照，加上网易云数据投影/大整数/扫码与账号验证/旧账号与旧页面响应丢弃/取消与到期/媒体网关，以及酷狗具体 IPC、扫码与账号一致性、过期、SSA、旧响应丢弃、歌单视图隔离、流主机和试听边界。全部使用明确标识的合成平台响应，不调用真实登录。

test:playback 有 4 项实际 mpv 场景，使用 null 输出与合成 WAV，检查原有本地行为和经 loopback 网关的真实 HTTP 解码、试听长度限制、旧解析取消、本地切换与网关清理；其中包含合成酷狗资源与跨平台媒体主机隔离。这证明控制和解码链路，不等同于扬声器出声或发行包兼容性。

test:e2e 先构建，再启动实际 Electron，检查桥接/沙箱、弹窗与导航、960×640 布局以及本地选择/播放/暂停/定位。只替代原生选择器交互，使用实际 mpv 和默认系统音频输出，拒绝 null 输出；关闭应用后验证 mpv PID 已退出。需要 Linux、mpv、可用的图形和音频会话。Playwright 显式启用 chromiumSandbox；通过 /proc 检查 renderer 的 Seccomp 与 NoNewPrivs。临时配置和合成文件会清理，截图留在 Git 忽略的 artifacts/；不需要下载 Playwright 浏览器。

桌面 E2E 也实际启动网易云与酷狗 utilityProcess，验证匿名 getState/本地退出及窄桥接，禁止自动生成真实二维码或授权账号。pnpm probe:netease、pnpm probe:kugou 是显式匿名联网探测，不在 CI 执行。真实听音与权限结果独立记录在 [网易云验证](validation/2026-10-26-netease.md) 与 [酷狗验证](validation/2026-10-26-kugou.md)。

CI 执行文档、冻结安装、类型、合成契约、mpv null 集成测试和构建；没有真实平台登录、图形、安装包或系统音频验收。远端 CI 结果需实际观察。

## 实现后的测试分层

| 范围 | 必须覆盖的行为 |
| --- | --- |
| Provider 契约 | 字段缺失、错误状态、分页、渠道区分、会话过期、权限限制 |
| 登录状态 | 扫码过期、取消、关闭窗口、断网重试、旧 Challenge 返回 |
| 队列与音频 | 连续切歌、重复曲目、随机历史、旧事件丢弃、进程退出与重启 |
| 缓存与存储 | 跨账号隔离、退出清理、事务、迁移、缺失或移动的本地文件 |
| 界面 E2E | 导航、搜索、队列控制、可见错误、键盘操作 |
| Linux 实机 | MPRIS、X11/Wayland、音频设备、托盘缺失、密钥服务缺失 |

纯逻辑和契约测试使用脱敏固定响应；真实账号验证只经用户授权的官方登录流程，在本机人工完成。CI 不注入平台 Cookie 或 Token。

## P0 接入验收

网易云、酷狗分别完成登录、账号读取、私人歌单读取、曲目解析和实际播放。重启恢复、退出清理、链接过期、权限拒绝分别记录。昵称和头像出现不作为接入完成依据。

酷狗网页登录与 App 扫码分渠道记录。无法播放时区分身份状态、Token 渠道、曲目权限和网络问题，不擅自判断为会员问题。

使用 [验证模板](templates/p0-validation.md) 记录每次实验。结果状态只能是未执行、通过、失败、受限；“受限”要写明实际可用能力和影响。

## Linux 发行验证

首批覆盖 Ubuntu/Debian、Fedora、Arch 的代表环境。记录精确版本、架构、桌面、显示协议、音频服务、Electron 与 mpv 版本。具体目标见 [设计方案](design-and-architecture.md)。

每个发布渠道检查安装、启动、声音、切歌、媒体控制、退出、重启与卸载。AppImage 检查 FUSE 和解包路径；原生包验证 mpv 及系统库依赖。构建成功或无界面容器通过不代替实机验收。
