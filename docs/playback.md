# 本地播放基础

Linux 已实现本地播放、网易云与酷狗单曲播放；第三步本地验证为基础，第四步扩展为通用 MusicPlayer。界面可一次选择最多 200 首本地音频，替换队列并播放第一首；选择在线曲目会追加到统一队列并切换播放，也可仅插入当前项之后，等到播放时才解析资源。已支持下一首插队、移除非当前项、清空后续曲目与 EOF 顺序续播；失败时停留并显示原因，不自动跳过。队列总数上限为 10000；本地一次选择上限仍为 200。队列抽屉展示全部歌曲并区分已播放、当前与待播放；“清空后续”只删除当前项之后的歌曲。目录扫描和标签仍待实现；播放核心已支持循环/随机，见下文。队列、顺序、当前歌曲、进度、音量和静音已支持持久恢复。

文件类型过滤包含 MP3、FLAC、WAV、M4A、AAC、Ogg、Opus、AIFF；实际解码以当前 mpv 构建为准。本轮实际音频样本为生成的 PCM WAV，不能据此宣称其他格式与发行版均已验证。缺失 mpv、文件不可访问、解码或音频输出失败显示明确错误；不自动切换到其他播放内核或静音输出。

## 模块与通信

- packages/playback/src/player.ts 拥有统一队列、路径/解析函数映射、独立 generation、revision 和唯一 PlaybackSnapshot。UI 只投影实际 mpv 状态。
- packages/playback/src/mpv-client.ts 使用 spawn 参数数组、shell=false 与继承 FD 3（input-ipc-client）通信。没有监听 socket/端口，没有临时 socket 文件；每个请求使用 request_id 与三秒超时，未知错误不透传原始 mpv 文本。
- src/main 只协调原生选择器、来源/参数校验、状态发布与退出。仅后端接触真实路径；文件异步 realpath/stat，确认是普通文件后传给 mpv。
- preload 暴露具体 playback 方法，不能指定 IPC 通道、文件路径、URL 或 mpv 命令。队列 ID 每次选择重新生成；UI 不能借 ID 请求未登记的文件。

PlaybackSnapshot 包含状态、队列 ID/标题/来源、可选歌手、平台曲目 ID 与实际音质/试听说明、当前索引、秒数位置/时长、0–100 音量、独立静音、播放记录保存错误、mpv 版本、实际音频输出驱动及安全错误，不含路径。renderer 先订阅再读取快照，按 revision 丢弃晚到旧响应；订阅在卸载时解除。

## 切歌与退出

每次切歌立即推进 playback generation；所有异步文件检查、进程事件和错误都检查所属 generation。串行切换先关闭旧进程并等待退出，再创建新进程，避免重复声音；过时的排队切换不启动新进程。为了让无 ID 的 mpv 属性事件也有明确归属，本阶段每首重建 mpv，代价是切歌存在初始化延迟，暂不支持无缝播放。

启动时禁用用户配置、脚本、视频窗口、外部字幕/音轨旁加载和间接文件引用，本地模式 lavf 只允许 file。新进程 loadfile 前清空 http-header-fields；当前网易云与酷狗都只接受无需账号请求头的 CDN 资源，其他需要凭据的媒体渠道仍需独立验证。

在线模式只对随机令牌保护的本机网关额外开放 HTTP/TCP；真实 CDN 地址和跳转由网关校验，mpv 不直接接收 Cookie 或签名源地址。网关按平台隔离网易云和酷狗媒体主机。退出某个平台会移除该平台的队列项；只有当前项来自该平台时才停止，不停止另一平台或本地音频。试听长度与 seek 上限均由后台约束。域名、Fake-IP、TLS 与媒体主机规则见 [网易云说明](netease.md) 和 [酷狗说明](kugou.md)。

停止和退出都会先使旧 generation 失效，再关闭 IPC。mpv 在继承客户端 FD 关闭后退出；超过 500ms 依次发送 TERM，再过 500ms 发送 KILL，并等待进程关闭。Electron before-quit 等待服务清理后再退出。进程异常终止显示错误，用户可以点击播放显式重建，不自动无限重启。应用音量设置在切歌时保留，不被新实例的默认音量覆盖。

## 播放记录与音量

底栏只保留一个播放模式按钮，依次切换列表循环 → 随机播放 → 单曲循环，图标、悬停提示和辅助名称均显示当前模式。`setMode` 通过一次具体 IPC 原子更新状态，随机与循环互斥；缺省为列表循环。随机启用时保持当前曲目并打乱其他队列项，一轮内不重复、到末尾结束；离开随机模式恢复原序，删除项不恢复。列表循环末尾回到第一首，单曲循环只在自然结束时重播当前项，手动切歌仍可换曲；错误不自动循环。

模式、随机队列与原序随播放记录保存。兼容旧记录时，旧组合开关中的随机优先，旧顺序/缺省模式转换为列表循环。SQLite 表结构不变，仅使用版本 1 记录已有的可选白名单字段，拒绝未知模式及损坏原序。MPRIS 的 LoopStatus 与 Shuffle 按三种模式互斥更新，具体映射及验证见 [模式验证](validation/2026-10-27-playback-modes.md)。

`userData/playback.sqlite` 与登录密文分库，由独立 Node worker 执行 SQLite 事务，主线程只异步协调。队列/设置更改合并 200ms，连续播放进度每 3 秒保存，正常退出前冲刷最新状态。异常断电或强制终止可能丢失最近尚未提交的数秒进度。文件权限为 0600，目录为 0700；它保存本地路径和平台账号 ID 等播放记录，不做加密，不保存 Cookie、Token、签名地址、封面原地址或权限缓存。损坏/未知版本保留原库并显示保存错误，不用空队列覆盖。

启动恢复队列和当前进度为暂停，不启动 mpv，不自动出声；用户点击播放后用 `--start` 从书签位置解码。本地文件仍需存在；网易云和酷狗曲目按平台/原账号绑定，临时未登录时保留队列并提示先连接原账号。连接别的账号移除该平台原账号项；显式退出移除该平台队列且保存删除，另一平台和本地歌曲保留。恢复时重新登记元数据、取链和校验当前权限；若本次只能试听，旧整曲书签也受当前试听长度限制。原账号登录恢复与完整权限矩阵仍需真实账号验收。

音量滑条有即时拖动反馈、35ms 请求合并、串行更新、方向键/Home/End 与滚轮；静音按钮保留选择的音量，再取消静音恢复此前数值。拖动后立即静音会等待最后一次音量提交，避免迟到响应重新开启声音。保存失败显示独立错误，不影响实际音频播放。验证见 [播放记录与音量](validation/2026-10-27-playback-session.md)。

## 验证

pnpm test:playback 使用真实 mpv、null 输出与现场生成 WAV；pnpm test:e2e 使用实际 Electron/mpv 和默认系统音频输出，只替代原生文件选择器交互。null 输出只在测试构造参数中显式启用，产品无相关开发开关。详细结果见 [P0 记录](validation/2026-10-26-local-playback.md)。

API 行为参考 [mpv 官方手册](https://mpv.io/manual/stable/) 的 JSON IPC、input-ipc-client、loadfile、access-references 与 current-ao。

## 当前歌曲歌词与封面

`PresentationController` 随唯一 PlaybackSnapshot 的 generation/曲目 ID 选择当前在线歌曲，歌词与封面使用独立快照通道；音频位置更新不重复传输图片。preload 只提供 `presentation.getState()` 与 `onChanged()`，不能请求任意 ID、地址或歌词 accesskey。切歌、停止、退出时旧结果失效，歌词请求失败不影响音频播放。

网易云以已登记歌曲 ID 请求行级 LRC，专辑信息来自同 ID 的歌曲详情；酷狗以已登记主 hash 查询歌词候选并核对完整曲名，以 LRC 下载，封面来自该歌单项或按原 hash 精确关联的资源详情。后台分别处理歌词和封面失败。封面只从固定平台图片域名经 HTTPS 读取，拒绝私网 DNS、重定向、凭据、SVG 与过大响应；校验格式后仅将有大小上限的 PNG/JPEG/WebP 内存数据传给页面，不保存原地址。DNS 对本机代理 Fake-IP 的处理与音频网关一致。

独立“正在播放”页面显示专辑名、封面与按 mpv 秒数高亮/滚动的歌词，侧栏与底栏均可进入，不使用播放弹窗；返回恢复原来的来源、歌单、筛选、多选与滚动位置。只有底栏一组播放控件；页面切换不切歌、不创建音频实例。定位后重算当前行，暂停时重新进入也立即滚到该行，尊重减少动画偏好。本地内嵌封面、旁置歌词、逐字歌词、翻译合并与平台完整曲目矩阵尚未实现或验证，见 [记录](validation/2026-10-26-presentation.md)。
