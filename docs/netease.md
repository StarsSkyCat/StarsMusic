# 网易云 P0 接入

已实现 App 扫码、后台账号校验、私人歌单/曲目分页、按平台实际资源播放和本地退出。用户已反馈扫码、账号、歌单正常，并在 Fake-IP 兼容修复后确认实际出声；范围见 [验证记录](validation/2026-10-26-netease.md)。酷狗、系统密钥持久化和发行包仍待后续步骤。

## 固定协议基线

基线为 api-enhanced 4.41.1，源码提交 2db6684453297ee86dec0492842f2320b08182d9；本轮不是直接加载整个 SDK。审查发现其默认入口创建共享临时令牌文件、加载大量模块，请求失败可能打印完整响应，且流接口关联音源解锁依赖。本项目只以 Node.js crypto 实现所需 eapi/weapi 请求格式，端点白名单固定在 transport.ts；不启动公开 API 服务，不加载解锁、任意代理或任意 API 请求接口。

协议常量属于公开接口格式，不是用户凭据，也不能用于凭据存储保护。来源和 MIT 声明见 [第三方记录](../THIRD_PARTY_NOTICES.md)。二维码由 qrcode 1.5.4 在后台生成 PNG，只在页面内存显示。

## 登录与会话

在应用中点击“连接网易云”，由后台获取 key 并生成官方登录 URL 的二维码，用官方网易云 App 扫码并确认授权。没有密码输入、剪贴板导入或配置文件凭据入口；不读取系统浏览器的登录态。

平台请求、Cookie 和设备标识都留在专用 Electron utilityProcess 内存中；页面只收到二维码图、状态、昵称、歌单及曲目白名单字段。轮询每两秒一次，网络/限流错误退避到十秒，本地最长三分钟后要求重新获取；800/801/802/803 分别处理过期、等待扫码、待确认和待身份验证。

803 本身不代表登录完成。后台必须确有身份凭据，并用账号接口验证 account.id 与 profile.userId 一致后才进入 connected。账号登录不代表歌曲权限或音质可用。

取消、重新登录、退出与账号过期均推进会话 generation，取消旧请求、清理临时凭据及私人列表，过期成功/失败都不能覆盖新状态。后台进程退出会清空公开投影并停止相关在线音频；主进程维持跨后台重启的 generation，旧队列不能借相同计数重新使用新账号会话。本地音乐不随网易云退出停止。

本轮不记住登录、不落盘 Cookie，不提供重启自动恢复。退出指本应用清理临时登录，不保证撤销平台在其他设备上的所有会话。

## 歌单与播放

登录后点击“读取我的歌单”。歌单和曲目每批 50 条；只允许请求本次账号已登记的歌单/曲目 ID。平台数字 ID 在安全数值范围内转为 string；超出安全整数的 JSON 数字保留原始十进制文本，不先舍入再转换。

当前使用基线版本的 song_url 端点，请求 128kbps，展示平台实际返回的 level/type/bitrate；未知音质保持未知。未使用新版 xeapi 自动密钥注册和共享缓存。无资源、权限错误、试听、链接失效分别按实际字段处理，不自动换源或推断会员状态。

选择一首网易云曲目会替换临时播放队列；当前只支持单曲解析播放，不自动把整张平台歌单加入队列。试听会明确标记，mpv 播放长度和可定位范围均受试听上限约束。位置/暂停/音量沿用唯一播放器状态源。

## 媒体网关

签名资源地址只在后台内存流转。mpv 通过随机令牌保护的 127.0.0.1 临时网关读取音频，地址由私有 FD 传给 mpv，不在命令行或页面上出现；只支持 GET、HEAD 和单 Range。

网关仅允许 HTTPS 且主机严格属于 .music.126.net，每次重定向重新验证，最多三次。平台历史响应的 HTTP 链接只尝试同域 HTTPS，不向 HTTP 降级。TLS 证书验证保持开启。DNS 拒绝环回、普通私网与链路本地目标；兼容本机 DNS 代理常用的 198.18.0.0/15 Fake-IP 映射，仍按原始官方 CDN 主机校验证书。当前解析限 IPv4，不提供任意代理配置或全域名兼容承诺。

只向 CDN 转发音频 Accept 与经校验的 Range；不转发账号 Cookie、Authorization 或本机请求携带的身份头，也不向 mpv 返回上游 Set-Cookie。网关随切歌、停止、退出、登录失效关闭。每首新建 mpv，先退出旧实例并清空请求头，不重复启动音频进程。

## 开发验证

- pnpm probe:netease：显式匿名联网获取二维码 key，只输出是否通过和固定基线，不输出 key、二维码或响应原文；不登录真实账号。
- pnpm test：合成响应验证登录状态、账号一致性、旧请求丢弃、分页视图隔离、数据投影与网关边界。
- pnpm test:playback：实际 mpv 解码合成远端音频，验证 HTTP Range 网关、试听上限、取消与本地切换。
- pnpm test:e2e：验证真实 utilityProcess 启动/退出与桥接，保持登录状态为空，不自动生成或截图真实二维码；本地音频继续用真实 mpv/PipeWire 验证。

真实账号测试只在官方 App 中授权，不在 CI 自动登录。完整免费/会员/购买/试听/不可用权限矩阵、链接过期后自动重新解析一次、实际 CDN 故障恢复、更多音质和跨发行版音频仍需补测；不把单账号闭环成功外推为全部歌曲可用。
