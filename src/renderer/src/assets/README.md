# 界面素材

stars-night.png：2026-10-26 使用内置 Image Gen 为 StarsMusic 生成的星夜、群山与湖泊背景，用于独立“正在播放”页面的默认配图与氛围底色。不是平台返回的专辑封面，不包含参考播放器的代码、品牌或视觉资产。在线当前曲目已接入经过后台校验的实际封面，缺失或读取失败时使用此原创默认背景。

界面线性图标来自 @lucide/vue 1.61.0，具体许可见 [依赖记录](../../../../docs/dependencies.md) 与 [完整声明](../../../../docs/licenses/lucide.txt)。

2026-10-27 的 Liquid Glass 主视觉在 GlassScene.vue / style.css 中以原创 CSS 绘制唱片、轨道与玻璃珠；不是新下载的图片，也不是实时音频分析。其余极光、来源卡装饰与按钮高光同样由 CSS 生成，没有复制其他应用的代码或视觉资产。
