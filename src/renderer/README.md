# 界面

Vue 3 + TypeScript 的云瓷白 / 曜石黑双主题 Liquid Glass 桌面界面，包含音乐库、本地音乐、网易云、酷狗、账号设置、播放队列抽屉和独立“正在播放”页面。不使用页面存储保存登录、队列或媒体地址。

- App.vue 协调导航、当前列表筛选、多选、歌单打开和 UI 状态；playback 始终来自后台唯一 PlaybackSnapshot。
- GlassScene.vue 使用原创 CSS 唱片、轨道和玻璃珠构成音乐库与播放空状态主视觉，只作装饰，不模拟音频频谱。style.css / themes.css 集中管理玻璃材质、薄荷强调色、静态极光背景、页面布局和按钮状态；没有新增依赖。
- TrackTable.vue 展示歌曲、歌手、来源与已知时长，支持选择、双击/按钮播放、下一首、移除非当前队列项。多选插队保持列表顺序。
- PlaybackControls.vue 是底栏唯一一组播放、暂停、上/下一首、停止和定位控件；页面切换不重建音频或播放时钟。
- NowPlayingPage.vue 是主内容独立页面，展示封面、专辑与歌词；舞台填满主内容高度，歌词无框悬浮、文字水平与当前行垂直居中，字号/行距按区域宽高缩放、远行淡出；歌词内部独立滚动、下一首贴近内容底部，封面/信息垂直居中；侧栏/底栏进入，返回保留浏览来源、歌单、筛选、多选及滚动位置。队列仍为独立抽屉，歌词不使用 dialog。
- useProvider.ts 为两个平台分别订阅快照，按 revision 丢弃旧响应；连接成功自动读取歌单。ProviderAccount.vue 复用真实扫码、取消和退出流程。
- TrackLyrics.vue 将当前歌曲的带时间戳歌词投影到 mpv 位置，暂停/定位共用后台时间，旧 generation 不显示；ResizeObserver 监听外层可用高度，窗口缩放后即时居中当前行，并在离页时断开监听；封面仅接受后台校验后的内存 PNG/JPEG/WebP 数据。
- ProviderAccount.vue 在二维码区域提供对应平台“记住登录”；useCredentials.ts 共用带 revision 的状态订阅；CredentialPanel.vue 仅显示保存状态、清除和存储不可用提示，设置页没有全局保存开关。二维码只在内存显示，不导出到截图或本地存储。

玻璃分层用于侧栏、主视觉、来源卡、账号卡、队列与播放舱；实心白底二维码保持可扫描。小窗口压缩侧栏辅助内容，主内容独立滚动；支持键盘跳到主内容、当前导航标识、焦点轮廓、禁用状态和减少动态效果偏好。背景不持续运动，真实音频分析尚未实现，未测量 GPU 性能。

筛选仅作用于已加载列表，不是在线搜索。本地文件选择会替换会话队列；在线播放追加并切歌，加入下一首仅登记后台解析函数。平台歌单是只读视图，暂不支持创建或编辑。当前在线歌曲已接入行级歌词和专辑封面，失败时分别显示缺失状态或默认背景；本地标签/封面/歌词、随机/循环、目录音乐库和队列跨重启恢复待实现。素材来源见 [说明](src/assets/README.md)，新增范围见 [歌词与封面记录](../../docs/validation/2026-10-26-presentation.md)，最新视觉验证见 [液态玻璃记录](../../docs/validation/2026-10-27-liquid-glass.md)，导航验证见 [页面记录](../../docs/validation/2026-10-27-listening-pages.md)。

外观设置由 AppearancePanel.vue 提供原生单选框，useAppearance.ts 在挂载前读取后台偏好，监听系统颜色方案实时切换语义颜色。公开的主题枚举通过 appearance 白名单保存到独立 JSON 文件，失败回退并显示错误；页面不写 localStorage。见 [双主题验证](../../docs/validation/2026-10-27-appearance.md)。

播放舞台适配与双主题尺寸矩阵见 [验证记录](../../docs/validation/2026-10-27-listening-layout.md)。

侧栏将本地音乐放在音乐来源分组第一项，随后为网易云和酷狗。左下会话队列使用单个原生 button 承载整块卡片，边缘、说明和数量均可点击，支持 Enter / Space。最新范围见 [悬浮歌词与侧栏验证](../../docs/validation/2026-10-27-floating-lyrics.md)。
